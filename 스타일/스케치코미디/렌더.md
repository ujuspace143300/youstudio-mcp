# 스케치코미디 · 굽기 지침 (러너 유지보수용)

숫자는 [규격.json](규격.json)에 있다. 여기는 sketch2 에서 실제로 터진 함정만.

## 글꼴 — 조용히 망가지는 자리 두 곳

- ★★★**PIL 이 글꼴을 못 찾으면 `load_default()` 비트맵으로 떨어지고 `size` 가 통째로
  무시된다.** 헤더 글자가 안 커진 진짜 원인이 이것이었다 — 값이 아니라 글꼴 문제.
  **반드시 진짜 글꼴로 떨어지는 사다리**를 두고, 끝까지 못 찾으면 **실패로 멈춘다.**
  ★맥 이식: 원본 사다리는 `malgunbd.ttf → malgun.ttf`(윈도우 전용) — 자산 글꼴로 교체한다.
  `os.path.join(HERE, "")` 은 폴더를 돌려주므로 `isfile` 로 거른다.
- ★★**얼굴 검출 모델(yunet.onnx)이 없으면 오류 없이 확대가 1.24 로 굳는다.** 실제로 한 편을
  그렇게 뽑았다. build 가 조각마다 얼굴 수를 찍는다 — 「얼굴 0」이 보이면 모델부터 확인.

## ASS 자막

- ★★**`Format:` 줄을 줄여 쓰지 마라.** 15개로 축약했더니 libass 가 값을 어긋난 자리에서
  읽었다. **22개 필드 전부** 쓴다.
- ★`ass` 필터 경로는 `ass` 와 `fontsdir` **둘 다** 콜론을 이스케이프한다. 한쪽만 하면 필터
  체인 파싱이 통째로 실패하고 에러 메시지로는 원인이 안 보인다.
- ★`WrapStyle` 을 2(줄바꿈 없음)로 두지 마라 — 긴 자막이 화면 밖으로 나간다. 0 + 자수 상한.
- 댓글 글꼴은 자막 글꼴을 쓰지 않는다 — 너무 굵어 댓글로 안 보인다. 얇은 회색이라야
  「남이 쓴 댓글」로 읽힌다. ★맥 이식: 원본은 `Malgun Gothic` — 대체 글꼴 확정 필요(사람 눈 확인).

## 나레이션

- ★★**나레이션 자막의 정본은 `segments[].narration` 이다** — `subs` 에 같은 문구를 두면
  한쪽만 고쳤을 때 어긋난다(실제 사고: 화면에 옛 문구가 나와 좌우로 넘쳤다).
  **먼저 굽고, 구운 음성의 실제 길이를 그대로 자막 길이로 쓴다.**
- 나레이션 동안 원음 덕킹 + 대사 자막 감춤(규격 `narration.duck_db`·`hide_line_subs`).

## 프레임 단위 마진 (지침서 4장)

- ★★원본 fps 를 100% 그대로. 꼬리 3~5F · 액션 버퍼 15~30F · 숨고르기 0.5~1.5초 ·
  리액션 인서트 0.3초 · 펀치라인 크래시 줌 + 임팩트 · 극적 발언 뒤 1초 정적.
- ★★**빠른 호흡만 쫓다 내용을 못 알아보게 만들지 마라** — 지침서가 가장 여러 번 반복하는 경고.

## 얼굴 프레이밍 (규격 `layout.video_box` 주석에 실측 근거)

- 먼저 전부 찾아 궤적을 다듬은 뒤(smooth) 구도를 정한다. 떨림은 부호 바뀐 횟수로 잰다.
- 얼굴은 큰 것부터 정렬 · 세로 6% 미만은 배경(액자·행인)이라 버린다 · 두 번째 얼굴은 큰
  얼굴의 45% 이상일 때만 주인공으로 본다 · 감싼 폭이 얼굴의 3배(pair_max_span)를 넘으면 큰 쪽만.

## 자막은 두 번 뽑는다 (흐름 규칙)

1차 렌더(cut.mp4 생성·TTS) → **subs 재추출**(cut.mp4 만 본다 — 계획 자막은 원본 전체 기준이라
성기고 어긋난다, 실측 19줄 → 31줄) → **asr**(실제 발화 시각, 요금) → **sync**(줄 단위로 시각만
맞춤 — 모델 추정은 줄마다 -1.1~+1.6초, 중앙 +0.12초라 일괄 보정으로는 못 고친다. **문구는
모델 것, 시각은 ASR** — ASR 문구는 오인식이 많다) → 재검사 → 2차 렌더(TTS 캐시 재사용).

## 외부 호출 (runner gem.py)

- 멀티모달은 EvoLink 우선(5~7배 빠르고 503 없음) — `User-Agent` 없으면 멀티모달만 403,
  `contents[].role` 없으면 에러 없이 타임아웃. 18MB 초과는 순정 Gemini(Files API).
- yt-dlp 가 낡으면 **미디어만** 403(메타데이터는 멀쩡해서 헷갈린다) — nightly 로 갱신.
- OpenCV 는 비ASCII 경로를 못 읽는다 — 이미지는 PIL, 모델은 임시 ASCII 폴더 복사.
  ★맥 이식: 한글 파일명 NFD → 비교 전 NFC 정규화.
