# 영화롱폼 — 나레이션 집필 지침

> script 단계에서 클로드가 읽는 지침. 서버가 이 파일을 그대로 내려보낸다.
> **결정(2026-08-16): 지무비체를 그대로 채택한다.** 목소리 차별화는 후속 판에서 규격을 바꿔 한다.
> 숫자는 여기 없다 — 대역은 `정답지.json` 「대본」, 설정값·금지 목록은 `규격.json` 「나레이션」. 서버 ② 검사가 그 값으로 잰다.
> 근거 원문 요지: `설계/참고_대본지침.md`.

## 0. 나레이션이 하는 일

대사(원음)가 앞장서고, 나레이션은 그 **사이 틈**에 조각으로 끼어들어 **원인·의미·속내**를 얹는다. 대사를 다시 옮기지 않는다. 화면에 있는 것을 말한다. 채울 것이 없으면 짧게 끝내는 것이 정답이다.

## 1. 목소리 (지무비체)

- **존댓말 단정체.** 문장은 `~습니다`계와 `~죠`계로 끝낸다 — 둘이 문장의 대부분이다. `~요`(어요/네요)로 끝내는 습관은 아주 조금만. 의문형은 드물게. **평서체(`~한다/~된다/~였다`)는 쓰지 않는다.** 같은 어미를 세 문장 이상 잇지 않는다. 배합률은 정답지 「대본.어미_배합」.
- **나레 레지스터** — 나레와 대사는 쓰는 말이 다르다. 나레에 「하지만/그러나/근데」를 쓰지 않는다 → **「허나」**. 「~겁니다」 → 「~것입니다」. 나레는 문어체 접속사(허나·무릇·그야말로·이어서·한편·무려). 치환표는 규격 「나레이션.나레_레지스터_치환」.
- **`..` 조각 문체** — 한 문장은 조각 두세 개로 흩어져 대사 사이에 놓인다. 문장을 끝내지 않고 다음 조각으로 넘길 때 `..`(점 두 개)로 흘린다. `..`는 낭독이 쉬는 자리이지 문장 끝이 아니다. 끊는 자리는 셋뿐 — ①체언+조사 ②용언 연결·관형형 ③접속어 단독(「그렇게..」「허나..」「무려..」). 맨 명사·부사 뒤에서 끊지 않는다. 한 문장에 몇 개까지인지, 미완결 문장이 얼마나 되어야 하는지는 정답지 「대본」.
- 형태는 `..` 하나뿐. `...`·`…`·`~` 금지. 세게 닫을 때만 `..!` (같은 위치에서 한 번). `..?` 금지. **마침표(`.`)와 쉼표(`,`)는 쓰지 않는다.**
- **길이** — 짧게 쓰는 것이 잘 쓰는 것이 아니다. 문장·조각 길이 대역은 정답지 「대본.문장_자수」「조각_자수」, 상한은 규격 「나레이션.문장_최대자수」.
- **유머 강도는 장르가 정한다.** 이 스타일의 기본은 "구어체 드립·밈감"이되, 드라마는 **드립 대신 감정 한 줄 — 따뜻한 단정, 인물 편에 서서 담담하게**. 호러·스릴러는 웃기려 들지 않는다. 케이퍼·코미디는 자주 친다.
- **금지 표현** (규격 「나레이션.금지표현」, 기계 검사): 「여러분은 알고 계셨나요」「충격적인 진실」「소름 돋는 복선」「역대급 반전」「이 장면은 정말 미쳤습니다」「아무도 알려주지 않은 비밀」「무조건 봐야 합니다」「이 작품은 단순한 ○○가 아닙니다」. 낚시 대신 **실제 벌어진 일·수치·행동**으로 끈다. 정리형 상투구(「운명의 장난」「비극의 서막」…)는 장면에 밀착한 구체적 반응으로 바꾼다.
- **군더더기** — 같은 뜻이면 글자 적은 쪽. 우회 표현(`~던 것이었죠`→`~였습니다`, `~인 셈이죠`→`~입니다`) 금지. 라벨 명사(대가·이유·의미·정체)를 주어로 세우고 긴 수식을 붙이지 않는다 → 행위자 주어 + 동사.

## 2. 내용 (공학 규칙)

- **인과** — 나레 블록 세 개 중 하나 이상은 앞 장면·대사의 **원인·동기·대가**를 말한다. 「무엇이 벌어졌다」가 아니라 「무엇 때문에 그렇게 됐다」. 원인은 사건 목록·전사·화면에 실재하는 것만.
- **되풀이 금지** — 직전 대사를 한국어로 다시 옮기면 정보 0. 나레는 그 위에 결과·의미·속내를 한 발 더 얹는다.
- **환각 금지** — 사건 목록(brief)·전사·시각 판정·facts 에 없는 사건·대사·이름을 만들지 않는다. 분량을 채우려고 없는 장면을 짓지 않는다. 지금 화면에 없는 사건을 지금 일어난 일처럼 쓰지 않는다(배경은 한 블록 이내).
- **사실 / 근거 / 해석** — 확인된 것은 단정. 추론은 해석 표현(규격 「나레이션.해석표현」)으로, 아껴 쓴다. 감독 의도를 단정하지 않는다.
- **이름** — 사건 목록·전사에서 확인된 이름만. **한글로, 성은 빼고, 짧게**(「마이클」). 확인 안 되면 관계·행동으로 부른다(「정장 남자」「목발 여자」). 번호 지칭(남자1) 금지. 신분·직업·나이·장소는 확인될 때만 단정, 애매하면 관계·행동으로 완화.
- **훅(도입)** — 이름·직업·시제를 서둘러 말하지 않는다. 넓은 공간 → 좁은 공간 → 익명 인물 → 능력·위기 → 이름 순.
- **시점 표지어** — 시간·장소가 바뀌면 조각 하나를 표지어로(「한편 같은 시각..」「이어서..」「몇 시간 뒤..」). 회상을 열 때는 반드시.
- **결론 예고 금지** — 어느 위치의 마지막 문장에서 다음 위치의 결론(반전·죽음·배신의 결과)을 미리 말하지 않는다. 조짐까지만.
- **브리지** — selection 의 「나레이션 브리지 후보」는 선택되지 않은 구간이다. 앞뒤를 **한 문장으로 잇는다**(그 사이 사건 목록의 사건을 한두 마디로 접는다). 브리지에서 새 사건을 길게 설명하지 않는다.
- **시각 사실** — 전사에는 없고 판정·facts 에만 있는 것(노화 반전·광대 분장·낙상·블랙)은 **나레가 말해 줘야 시청자가 안다.** 시각몽타주 구간의 나레는 여기서 나온다.

## 3. 스포일러 · 결말 · 아웃트로

- 결말 모드는 규격 「나레이션.결말모드」. 기본 `spoiler`(결말 공개) — 정답지 스타일이 그렇다. `no_spoiler` 로 바꾸면 규격 「나레이션.노스포_금칙」의 어휘 표(반전 예고·결말/생사 노출)를 기계가 검사한다.
- **시청자 향한 수사의문 금지** — 모드와 무관하다(「당신이라면」「여러분의 선택」…). 규격 「나레이션.시청자_수사의문_금지」.
- **아웃트로** — 정보 고지로 끝내지 않는다(「지금까지 …였습니다」「N년작이었습니다」·감독/러닝타임 고지). **질문으로 끝내지 않는다.** 승인된 닫는 법: 제목 회수(「그래서 제목이 …였던 거죠」) · 명대사 원음 콜백 · 수미상관(첫 문장 뒤집기) · 인물 후일담 · 주제 전복 · 정적 엔딩(나레 0) · 한 줄 촌평. CTA(구독·다음 편)는 나레가 아니라 별도 카드.

## 4. 블록 모양 (서버 ① 이 내려주는 형식)

블록마다 **위치·본문·의도**.
- `pos.kind`: `over`(구간 위에 — 나레이션덮기·시각몽타주 구간) · `before` / `after`(원본대사 구간의 앞/뒤 짧은 이음) · `bridge`(브리지 후보 k 안).
- `text`: 한 문장(조각은 `..` 로 이어 붙인 한 블록). 한 블록에 여러 문장을 넣지 않는다.
- `intent`: 이 블록이 하는 일 한 줄(원인 / 의미 / 속내 / 표지어 / 시각 사실 / 이음 / 닫기 …).

## 5. 통과 기준 (서버 ② 가 잰다)

hard: 금지 표현·정보 고지·수사의문 0건 / 평서체 어미 0 / 레지스터 위반 0 / `..?`·`...`·`…`·마침표·쉼표 0 / `..!` 위치당 1 이하 / `..` 한 문장 상한 / 문장 상한 자수 / **나레 시간점유**(나레 추정 시간 ÷ (나레 추정 + 원본대사 발화 시간), 대역은 정답지 「대본.나레_시간점유」 — 추정이므로 voice 실측 뒤 재검).
soft(경고): G-턴비(시간비·블록수비), 문장·조각 길이 대역, 미완결 비율, 어미 배합, 같은 어미 연속, 상투구.
불통 메시지는 **어느 블록 어느 문장이 왜**인지와 **수리 지침**을 담는다.
