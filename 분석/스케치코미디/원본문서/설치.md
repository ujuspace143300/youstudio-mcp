# sketch2 — 다른 컴퓨터에 옮기기

이 폴더만 있으면 돈다. 다만 **이 PC 밖에 있는 것 네 가지**를 갖춰야 한다.

## 1. 파이썬과 꾸러미

파이썬 **3.12** 를 쓴다(3.10 이상이면 대체로 된다).

```powershell
python -m venv C:\Users\<나>\.volcano\venv
& C:\Users\<나>\.volcano\venv\Scripts\python.exe -m pip install ^
    pillow numpy opencv-python fonttools
```

`harness/pipeline.json` 의 `python` 이 `~/.volcano/venv/Scripts/python.exe` 를 가리킨다.
다른 자리에 만들었으면 그 줄만 고친다.

★**opencv-python 이 있어야 얼굴을 찾는다.** 없으면 오류 없이 「얼굴 0개」가 되어
화면이 굳은 채로 구워진다.

## 2. 외부 도구 — PATH 에 있어야 한다

| 도구 | 쓰는 곳 | 받는 법(윈도우) |
|---|---|---|
| `ffmpeg` · `ffprobe` | 자르기·합성·측정 | `winget install Gyan.FFmpeg` |
| `yt-dlp` | 원본·자막·댓글 받기 | `winget install yt-dlp.yt-dlp` |
| `deno` | ★yt-dlp 의 유튜브 서명 풀이 | `winget install DenoLand.Deno` |

★**`deno` 가 없으면 유튜브 다운로드가 `403` 으로 죽는다.** 요즘 yt-dlp 는 JS 런타임
없이는 서명을 못 푼다.

★**yt-dlp 가 낡아도 같은 403 이 난다.** 메타데이터는 멀쩡히 나오는데 다운로드만
막히면 그 경우다 — `yt-dlp --update-to nightly` 로 올린다(winget 소스에는 최신이 없다).

## 3. 키 네 개

`C:\Users\<나>\.volcano\keys\` 아래 **파일**로 둔다. 값만, **줄바꿈도 BOM 도 없이.**

| 파일 | 쓰는 곳 | 없으면 |
|---|---|---|
| `evolink` | 영상·그림 분석 1순위 | 순정 Gemini 로 물러난다(느리고 503 잦다) |

★**메모장으로 저장하면 BOM 이 붙어 401 이 난다.** 눈에 안 보이는 고장이다.
환경변수(`EVOLINK_API_KEY` 등)로 줘도 된다.

## 4. 폴더 배치

압축을 풀면 이렇게 된다. **`harness/` 와 `vh.py` 는 같은 높이에 둔다.**

```
<작업폴더>/
  vh.py                 하네스 진입점
  harness/              하네스 엔진 (여러 파이프라인이 공유한다)
  sketch2/              이 채널
    make.py  config.json  s2pipe/  harness/  assets/  tools/
```

## 첫 실행

```powershell
$PY = "C:\Users\<나>\.volcano\venv\Scripts\python.exe"

& $PY vh.py status sketch2                      # 하네스가 보이나 · 키가 다 있나
cd sketch2
& $PY -m s2pipe.plan "<유튜브 URL>" --slug 시험_A   # 계획 (모델 1회)
cd ..
& $PY vh.py check sketch2/projects/시험_A.json     # 검사 (공짜)
```

`status` 가 키 하나라도 못 찾으면 첫 줄에 `⚠` 로 알려 준다.

## 굽는 순서

```powershell
cd sketch2
& $PY make.py projects/<편>.json          # 1차 (★TTS 요금)
& $PY -m s2pipe.subs projects/<편>.json    # 자막 다시 (cut.mp4 를 본다)
& $PY -m s2pipe.asr  projects/<편>.json    # 발화 시각 (★ASR 요금)
& $PY -m s2pipe.sync projects/<편>.json    # 자막 시각 맞추기 (공짜)
cd .. ; & $PY vh.py check sketch2/projects/<편>.json
cd sketch2 ; & $PY make.py projects/<편>.json     # 2차
```

**두 번 굽는 이유**는 `subs` 가 잘라 붙인 `cut.mp4` 를 봐야 하기 때문이다 —
첫 렌더는 그 파일을 만들려고 돌린다. TTS 는 캐시가 있어 두 번째에 다시 굽지 않는다.

## 안 들어 있는 것

- **원본 영상·완성본**(`work/` `out/`) — 용량 때문에 뺐다. 돌리면 새로 생긴다
- **BGM**(`assets/bgm`) — 아직 정하지 않았다
- 글꼴과 얼굴 모델(`assets/fonts` `assets/models`)은 **들어 있다**

## 막히면

그 단계 것만 꺼내 준다. 규격의 근거는 `config.json` 의 `_키` 주석에 있다.
