## A. 클릭 단위 절차 (편당 1회)

1. **AI Studio 열기** — https://aistudio.google.com → 왼쪽 위 **New chat**(새 채팅).
2. **모델 고르기** — 오른쪽 패널 Model 에서 **멀티모달 최신 모델**(영상 입력 가능한 것). 영상 입력이 안 되는 모델이면 URL 을 붙여도 못 본다.
3. **설정 두 개만 만진다** — Temperature **0**(같은 영상에 같은 답이 나오게), Output length 는 최대. 나머지는 기본값.
4. **유튜브 URL 붙이기** — 입력창에 아래 대응표의 URL **한 줄만** 먼저 붙인다. 영상 카드가 잡히는지 확인한다(카드가 안 뜨면 그 편은 URL 입력이 안 되는 것 → 「D. 안 될 때」).
5. **프롬프트 붙이기** — 아래 **C. 프롬프트 전문**을 통째로 복사해 URL 아래에 붙이고 **Run**.
6. **기다린다** — 15분짜리 영상은 보통 1~3분. 「분석 중」이 길어도 중간에 멈추지 않는다.
7. **JSON 만 복사** — 답의 코드블록(```json … ```) **안쪽만** 복사한다. 설명 문장은 버린다.
8. **저장** — `분석/지무비/NN/gemini.json` (NN 은 대응표의 번호, 폴더가 없으면 만든다). 파일은 **UTF-8**.
9. **검사** — 터미널에서 아래를 돌린다. 통과하면 다음 편으로.
   ```
   python 서버/runner/분석_판독검사.py --판독 분석/지무비/NN/gemini.json
   ```
10. 10편을 다 모으면 클로드에게 「판독 10편 저장 끝」이라고 알린다.

## 지켜야 할 것
- 답은 **JSON 하나만** 낸다. 코드블록(```json)으로 감싸고, 그 밖에는 아무 말도 쓰지 않는다.
- 모든 시각은 **초 단위 숫자**(예: 83.5). "1:23" 같은 표기를 쓰지 마라.
- **본 것만 적는다.** 확실하지 않으면 값을 넣되 그 항목의 "확신" 을 "낮음" 으로 적는다. 아예 판독이 안 되면 값은 null, 그 이유를 "판독_불가" 배열에 한 줄로 적는다.
- 지어내지 마라. 영상에 없는 장치·색·효과음을 채워 넣지 않는다.
- 자막이 두 종류(화면 위쪽 = 나레이션 해설 / 아래쪽 = 등장인물 대사)로 나뉘어 있으면 각각 따로 적는다.

## 판독할 것
1. 자막 레인: 나레/대사 각각의 화면 세로 위치(위 0.0 ~ 아래 1.0 비율), 가로 정렬, 폰트 인상(굵기·세리프 유무),
   글자 높이가 화면 높이의 몇 %인지, 글자 색(HEX 근사), 외곽선/그림자/배경 상자 유무.
2. 강조: 한 자막 큐 안에서 **일부 단어만** 색·크기·폰트가 다른 사례를 **최소 8개** 골라
   시각·자막 전문·강조된 단어·강조 방식(색 HEX·크기 배수)·왜 그 단어를 강조했다고 보는지·의미 유형을 적는다.
   의미 유형은 [숫자, 고유명사, 감정어, 반전어, 의성어, 행위어, 기타] 중 하나.
3. 효과음: 들리는 효과음을 **최소 5개**(있는 만큼) — 시각·종류 이름(휙/쿵/삐/두구두구 등)·무엇에 붙었는지

4. 전환: 하드컷이 아닌 전환(디졸브·플래시·줌 등)이 쓰인 시각을 있는 만큼.
5. 도입 30초: 장면이 어떤 순서로 나오는지, 나레이션 첫 문장, 훅 유형 [질문, 사건 제시, 결말 암시, 인물 소개, 기타], 훅이 끝나는 시각.

8. 전체 인상: 나레이션이 전체 말하기 시간에서 차지하는 비율(대략 %), 대사 자막이 있는지.

## D. 안 될 때

| 증상 | 대처 |
| :-- | :-- |
| URL 을 붙여도 영상 카드가 안 뜬다 | 모델을 영상 입력 되는 것으로 바꾼다. 그래도 안 되면 그 편은 **건너뛰고** 번호를 기록해 둔다(표본 9편으로 줄여 정직하게 적는다) |
| 답에 JSON 말고 설명이 섞였다 | 「JSON 코드블록 하나만 다시 줘」라고만 답한다 |
| JSON 이 중간에 끊겼다 | Output length 를 최대로 올리고 다시 Run. 그래도 끊기면 「강조는 8개까지만」으로 줄여 다시 요청 |
| 강조 사례를 못 찾겠다고 한다 | 그대로 저장한다(`강조: []`). 그 편은 강조 표본에서 빠진다 — **없는 것을 지어내게 하지 않는다** |
| 검사기가 오류를 뱉는다 | 오류 줄에 적힌 키만 고쳐 다시 저장하거나, 그 키를 물어 다시 Run |

## E. 저장 규칙

- 파일 하나에 **한 편**. 덮어쓰지 말고 번호 폴더를 따로 만든다.
- 판독은 **영상 자체 정보**만 담는다 — 영상 파일·프레임은 저장소에 넣지 않는다(내부 분석 전용, 재배포 금지).
- 프롬프트를 고치면 **이미 받은 편도 다시 돌린다**(같은 자로 재야 비교가 된다). 고친 날짜를 이 문서 아래에 적는다.
