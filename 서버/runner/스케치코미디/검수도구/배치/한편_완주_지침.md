# 싱글벙글 한 편 완주 지침 (배치용)

> 2026-09-27 사장님 «순서대로 100개 … 이전 교훈 잊지 말고 끝까지 완주해서 저장까지». 싱글286~270 17편에서 나온 교훈을 한 장에 모았다.
> 에이전트 하나가 **한 편**(싱글NNN)을 이 순서대로 끝까지 맡는다. 다른 편 파일·공용 코드는 **건드리지 않는다**
> (도구 버그를 찾으면 고치지 말고 보고에 적는다 — 여러 편이 같은 코드를 동시에 쓴다).

## 공통
- 한국어로 적는다. 사장님 호칭 «사장님». 설명·보고에 확인한 것과 짐작을 구분한다.
- 경로: 프로젝트 `~/Desktop/스케치코미디/projects/싱글NNN.json` · 원본 `~/Desktop/스케치코미디/work/<source.id>.mp4` ·
  원본 전사 `work/<source.id>.ko.vtt`(agy — **자막 재료 아님, 시각 참고용**) · 대조표 `work/싱글NNN/대조/표_NN.jpg` · 로그 `~/Desktop/스케치코미디/배치로그/`
- 도구 폴더 `R=~/Desktop/youstudio-mcp/서버/runner/스케치코미디`, 파이썬 `PY=~/.volcano/venv/bin/python3`, 설정 `export S2_CONFIG=~/Desktop/스케치코미디/config_숨은기록.json`
- 프로젝트 JSON 은 파이썬으로 읽고 고치고 되읽는다(한글 이스케이프 금지 · `ensure_ascii=False, indent=2`). **체인이 도는 중엔 고치지 않는다**(`.체인중` 잠금).
- 유료는 ② 굽기(Typecast 나레 1줄)·③ 재전사(Speechmatics 완성본 ~75초, 약 $0.02)뿐 — 사장님이 배치 전체를 승인했다. 재굽기는 필요할 때만.
- **EvoLink 금지.** agy 가 «민감한 낱말»(구글 안전 필터)로 거절하면(AgyStop) 같은 단계를 한 번 더 돌린다. 두 번 거절이면 그 편은 **보류**하고 보고.
- 다른 회사 광고(PPL — 앱·금융·쇼핑 홍보 대사/화면, 예: «빗썸 가입하면 11만 원») 는 넣지 않는다.

## ① 준비 (무료)
`bash $R/검수도구/배치/준비.sh NNN` — 편시작(agy 통째 전사 + 자막띠시각 맞춤) → plan. 실패면 로그 끝을 읽고 한 번 재시도, 또 실패면 보류.
- 편시작이 «원본 끝을 넘는 줄» 로 멈추면 `준비.sh NNN --다시` 한 번.

## ② 계획 점검·고침 (무료) — 여기서 제일 많이 틀린다
1. `$PY $R/검수도구/plan점검.py 싱글NNN` 으로 조각 표·Climax%·원본 끝 20초 전사·뺀 구간을 본다.
2. 반드시 확인하고 고친다(고침은 `계획고침.py 싱글NNN <patch.json>` 또는 파이썬으로 segments 직접):
   - **결말 포함**: 원본 마지막 펀치 대사(아웃트로 카드 직전)가 마지막 조각 안에. 스케치 결론은 원본 끝에 있다 — 빼지 않는다.
   - **길이 60~80초**, **Climax(phase 4) 시작이 60% 이상**, **나레 3초 이하**(한 줄 짧게), **훅이 본문에서 반복 안 됨**(겹치면 같은 대사 두 번).
   - agy 원본 전사 시각은 영상마다 늘어나 틀릴 수 있다 — 중요한 경계는 **박힌 자막 카드**(`from s2pipe import 자막띠시각; 자막띠시각.카드들(src)`)와 소리로 확인.
   - 앞뒤 흐름: 질문만 있고 대답이 빠지거나, 대답만 있고 질문이 빠지면 안 된다(발화 끝까지).
3. **제목**: `title_candidates` 에서 쇼츠 시청자가 누를 만한 것을 고른다(사장님 위임 — 묻지 않는다). 2줄·각 11자 이하·이모지 없음·
   **하단 원제(`credit.title`)와 달라야 한다**(make 관문이 닮음 0.75 이상 반려). 후보가 모두 약하면 지침서 어미(~의 정체·~하면 벌어진 일·~한 이유)로
   영상 내용에 있는 사실만으로 새로 만든다. `proj["title"]=[윗줄, 아랫줄]`, `proj["_제목_출처"]="plan 후보 — 사장님 위임(2026-09-27 100편 배치)"`.
4. `$PY $R/검수도구/경계제안.py 싱글NNN --쓰기` (대사 한가운데 경계를 조용한 곳으로) — 결과가 광고·다른 장면을 끌어들이지 않았는지 본다.
5. **`$PY $R/검수도구/카드경계검사.py 싱글NNN`** — 박힌 자막 카드가 경계를 가로지르면 문장 반쪽이 잘린 것(이음매 관문이 못 잡는다).
   걸리면 `--쓰기` 로 고치고, 고친 자리 앞뒤 소리를 재서(0.02초 간격 RMS) 옆 말이 딸려 들어가지 않았는지 확인한다.
   거짓 걸림(카드만 오래 남은 쉼·나레가 덮는 조각 머리)은 근거를 적고 둔다.
   늘어서 80초를 넘으면 **원본 화면 전환 자리**(`ffmpeg ... select='gt(scene,0.2)',showinfo`)에서만 덜어 낸다(같은 샷 안 자르기 = 튐 금지). 군말·반복부터 뺀다.
6. `cd $R && $PY make.py ~/Desktop/스케치코미디/projects/싱글NNN.json --check` 가 **«통과»** 여야 다음으로 간다. «결론 미포함» 이 agy 시각 탓 가짜면
   근거를 적고 `proj["결말확인"]=true`.

## ③ 굽기~작표 (유료)
`FROM=2 UNTIL=4 bash $R/검수도구/배치/체인.sh NNN`
- **④ 이음매 관문 반려**면: `$PY $R/검수도구/이음매수리.py 싱글NNN` 로 보고 `--쓰기` → 원본 소리로 확인(반려 낱말이 앞 조각 꼬리인지, 뒤 조각 머리인지 —
  싱글270 «없지+만» 은 **뒤 조각 머리에 앞 줄 꼬리 «만» 이 묻은 것**이었다) → make --check 통과 → 다시 `FROM=2 UNTIL=4`. 세 번 넘게 반려면 보류.

## ④ 자막 대조·핀 (무료) — 반드시 눈으로
1. `$PY $R/검수도구/자막대조표.py 싱글NNN` → `work/싱글NNN/대조/표_*.jpg` 를 **전부** Read 로 본다(왼쪽 = 우리 자막, 오른쪽 = 원본에 박힌 자막).
2. 원본 박힌 자막이 정답에 가깝다(확인 용도로만 — 글자를 통째로 베끼지 말고 들은 말과 다를 때만 고친다). `proj["문구교정"] = {"시각": "문구"}`:
   - `"문구"` 보통 핀 · `"=문구"` 정확 핀(줄 줄이기·통째 교체) · `""` 빼기 핀 · `"+문구"` 더하기 핀(전사가 통째로 놓친 짧은 말 — 시각은 박힌 카드와 소리로 확인)
   - 이름 오인 주의(이 작품 인물: 두현·지명·민지·단비·김두현 등 — 대조표 오른쪽 표기를 따른다).
   - 14자 넘는 줄은 관문이 쪼갠다. 0.3초보다 짧은 조각 줄이 생기면 줄여서 다시 핀.
3. 빠진 결말 대사(«먹을래?» 같은)가 있는지 마지막 표를 꼭 본다.

- 마지막으로 `카드경계검사.py 싱글NNN` 한 번 더(남은 걸림은 이유를 보고에).
