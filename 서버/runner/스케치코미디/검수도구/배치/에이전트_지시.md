# 배치 에이전트 한 편 지시 (띄울 때 시리즈·NNN 만 바꿔 준다)

사용: 에이전트 프롬프트 첫 줄에 `시리즈=점심이네 NNN=5` 처럼 적고 이 파일을 따르게 한다. 시리즈를 안 적으면 싱글벙글(`NNN=12` 만 적어도 된다).
아래 `<슬러그>` = 시리즈 접두 + 번호(앞 0 없이) — 싱글벙글 12 → `싱글12` · 점심이네 5 → `점심이네5`(NAS 폴더는 «05.점심이네_…» 여도 슬러그는 «점심이네5»).

<시리즈> NNN 편(`<슬러그>`) 한 편을 끝까지 만들어 NAS 에 납품하라. 절차·규칙·교훈은 `한편_완주_지침.md`(같은 폴더) — 먼저 끝까지 읽고(① 맨 앞 «agy 파악»과 «배치 중 굳은 요령») 그대로 따른다.

## 시리즈 표 (배치 도구는 `시리즈.sh` 가 이 값을 안다 — 준비.sh·체인.sh·납품.sh 에 `<슬러그>` 를 주면 시리즈가 따라온다)
| | 싱글벙글 (기본) | 점심이네 (2026-09-29 사장님 결정 · 64편) |
|---|---|---|
| 슬러그 | `싱글NNN` | `점심이네NNN` |
| 템플릿·설정 (`S2_CONFIG`) | 숨은기록 · `~/Desktop/스케치코미디/config_숨은기록.json` | **누룽지독**(Deep 에 쓰던 틀 · 로고 누룽지독 @yellow_dog — mp4 머리·prproj 둘 다) · `~/Desktop/스케치코미디/config_누룽지독.json` |
| 하단 출처 줄 | `#싱글벙글_원제` — 원제 = 원본 mp4 파일 이름의 «_» 뒤(편시작 기본) | `#점심이네 - 원제` — 원제 = 원본 mp4 파일 이름의 «_» 뒤(싱글벙글·Deep 전례와 같음 — 2026-09-29) |
| 소재 (NAS) | `3. 스캐치코미디/싱글벙글/NN.싱글벙글_…/` | `3. 스캐치코미디/점심이네/NN.점심이네_…/` |
| agy 파악 답 | `배치로그/agy파악/싱글NNN.md` | `배치로그/agy파악_점심이네/점심이네NNN.md` |
| 납품 (NAS) | `3. 스캐치코미디/싱글벙글/완성본/싱글NNN_원제/` | `3. 스캐치코미디/점심이네/완성본/점심이네NNN_원제/` (첫 편이 폴더를 만든다) |
| 납품 확인 | `python3 ~/Desktop/스케치코미디/배치로그/확인.py NNN` | `python3 ~/Desktop/스케치코미디/배치로그/확인.py --시리즈 점심이네 NNN` |
| 진행표 | `배치로그/진행.md` (`진행갱신.py 완료 띄운`) | `배치로그/진행_점심이네.md` (`진행갱신.py 완료 띄운 --시리즈 점심이네` — 없으면 틀을 만든다) |
- 파이썬 도구를 직접 돌릴 때는 그 시리즈 설정을 준다: `export S2_CONFIG=<위 표의 설정>` (점심이네에 숨은기록 설정을 주면 머리·출처 줄이 싱글벙글 틀로 나간다).
- 납품.sh 는 프로젝트 하단 채널(credit.channel)이 시리즈와 다르면 NAS 에 쓰기 전에 멈춘다.

## 공통 규칙 (모든 시리즈 — 싱글벙글 배치에서 굳은 것 그대로)
- agy 파악 답: 위 표의 자리(미리 돌려 둠, 같은 폴더 `<슬러그>.log` 끝 «종료=…»). 다시 부르지 말고 계획 점검 전에 읽어 흐름·결말·반전·아웃트로를 잡는다. 없으면 몇 분 기다리고, 종료≠0 이면 기존 방식.
- 이 한 편만 맡는다. 다른 편 파일·공용 코드는 고치지 않는다(여러 편이 동시에 돈다 — 공용 코드가 중간에 수리돼 바뀔 수 있다, 정상). 도구 버그는 보고에.
- 사장님에게 묻지 않는다(제목 위임 — 싱글벙글 2026-09-27 · 다른 시리즈는 띄우는 쪽이 위임을 확인하고 띄운다). 막히면 «보류». «절대 대충 만들지 말고» · «최적화 절대적으로 고려» — 재굽기는 결함이 프레임·소리로 확정됐을 때만 한 번. 관문 «주의» 만으로 다시 굽지 않는다. 같은 자리 세 번 넘게 고쳐도 안 되면 보류.
- ★원본 박힌 자막이 완성본에 보이면 안 된다(높이 뜬 카드·두 줄 카드·날짜 캡션·화면 속 캡션 포함) — 완성본 프레임에서 영상 상자 아래쪽·가장자리를 확대해 본다. 보이면 보고.
- ★원본 전사·카드 시각이 0.3~6초 늦거나 카드를 놓치는 일이 있다 — 결말 부근·중요한 경계는 프레임·소리로 직접 잰다.
- ★나레: 정확히 한 조각에만 1줄, 대사와 떨어진 대사 없는 샷 위(나레 시작 0.2초 안 대사 줄은 말없이 감춰진다 · 결말 조각이면 make 반려). 원본 성우 해설이 딸려 오지 않게.
- ★빼기 핀 «""» 는 가장 가까운 줄을 지운다 — 옆 줄이 사라질 수 있다. 핀 뒤 subs 로 꼭 확인.
- ★«전체화면»/«원문화면» 은 박힌 자막 없는 샷에만. 제목 줄 ≠ 자막 줄, 각 11자 이하, 영상 내용과 맞게(인물 관계·숫자).
- ★아웃트로: 원본 끝 채널 로고 카드(싱글벙글은 남색 로고 카드 · 협찬이면 «싱글벙글 x 브랜드» · 다른 시리즈는 agy 파악 답의 아웃트로 시각을 프레임으로 확인) 위 목소리 구간은 결말이 아니다 — 로고 시작을 프레임으로 재고 그 앞에서 끝(make 주의는 근거 적고 결말확인/결말절단허용). 결말 대사 끝까지. 80초 이하.
- PPL(영화·제품·앱·브랜드) 대사·화면·광고 댓글은 뺀다(plan 이 광고 중심이면 다시 짠다). 화면 전환은 필요하면 scene 0.08. 조각 끝을 늘릴 때 다음 말 머리가 딸려 오지 않는지 소리로.
- 훅은 본문에 다시 안 나오는 장면, 훅의 질문에 답하는 장면은 본문에. 원본 순서 유지. 반전·가장 웃긴 대목·셋업·뜻에 필요한 앞 대사는 빼지 않는다.
- 가짜 이음매 반려(소리 실측 확인)는 다시 굽지 말고 `이음매허용` 에 근거. 절정·반전 조각이 효과음(2.6초)보다 짧으면 ⑧ 실패 — phase 조정.
- ★핀은 «판정까지 끝난» ④ 출력의 대조표로. 핀 시각 = 대조표 줄 시작 그대로. 핀 뒤 마무리는 FROM=4, 그 뒤 subs 로 확인.
- agy 한도 절약: agy_call 로 따로 묻지 않는다. 편시작 agy 전사의 출력 한도 초과·시각 늘어남은 이제 스스로 나눠 전사하고, 구간 시각 대조(40초 창)가 줄 시각을 바로잡는다(2026-09-28·29) — 그래도 실패면 `준비.sh <슬러그> --다시` 한 번(통째가 거듭 틀리면 `--다시 --나눠`). 끊겨도 받은 답은 저장돼 있으니 그냥 다시 돌린다. 임시 나눠전사 스크립트를 만들지 않는다. 429 면 풀린 뒤 그 단계부터(EvoLink 금지).
- 체인 로그 `~/Desktop/스케치코미디/배치로그/<슬러그>_체인.txt`. 긴 명령은 timeout 600000 또는 run_in_background. 대조표 이미지는 전부 Read. 결말 샷은 완성본 프레임으로.
- 결과.tsv 에는 `>>` 로 한 줄만(줄바꿈 포함).
- 끝나면 한국어로 짧게 보고: 상태 · 제목 · 길이 · 고친 것 · 남긴 것과 이유 · agy 파악 답이 얼마나 맞았나 · 도구 버그.
- 체인을 기다릴 때 `pgrep -f "체인.sh <슬러그>"` 대기 루프를 쓰지 않는다(자기 자신을 잡아 끝나지 않는다 — 132·151). 체인은 run_in_background 로 띄우고 완료 알림을 받는다. 체인 출력은 `배치로그/<슬러그>_체인.txt` 에 스스로 적힌다(다른 파일로 덮어쓰지 않는다 — 134).
