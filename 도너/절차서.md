# 도너 prproj 만들기 — 절차서 (프리미어 프로 26.3.2 · 한국어 UI · 사람이 한다)

이 파일 하나가 우리 산출물의 **뼈대**가 된다. 프로그램은 여기 있는 트랙·클립·자막 견본을 **그대로 복제**해서 본편을 채운다. 그러니 여기서 자막을 **눈으로 완벽하게** 잡아 두면 산출물이 그대로 따라온다. 15~20분.

**시작 전 체크**
- [ ] 산돌구름 앱이 켜져 있다(트레이 아이콘). 꺼져 있으면 폰트가 대체 서체로 박힌다.
- [ ] `C:\Users\user\Desktop\youstudio_work\fulltime\` 에 원본 mp4(`…\볼케이노 MCP\쇼폭_영화롱폼\23. FULL TIME  Omeleto.mp4`)와 `voice\b01.wav` 가 있다.
- [ ] 이 폴더 `C:\Users\user\Desktop\youstudio-mcp\도너\` 가 있다(있음).

## 1. 새 프로젝트
1. 프리미어 실행 → 홈 화면 **새 프로젝트**(New Project).
2. 프로젝트 이름: `영화롱폼_donor_ppro26.3` · 위치: `C:\Users\user\Desktop\youstudio-mcp\도너` (「찾아보기」로 지정).
3. 아래 「가져오기」 화면에서는 **아무 파일도 선택하지 말고** 오른쪽 아래 **만들기** 클릭 → 빈 프로젝트가 열린다.

## 2. 시퀀스 만들기 (1920×1080 · 23.976)
1. 메뉴 **파일 > 새로 만들기 > 시퀀스**(Ctrl+N).
2. 위쪽 탭 **설정** 클릭.
   - 편집 모드: **사용자 정의**
   - 시간 기준: **23.976 프레임/초**
   - 프레임 크기: 가로 **1920**, 세로 **1080** (16:9)
   - 픽셀 종횡비: **정사각형 픽셀(1.0)**
   - 필드: **필드 없음(프로그레시브 스캔)**
   - 오디오 샘플 속도: **48000 Hz**
   - 미리 보기 파일 형식: 그대로 두어도 됨
3. 위쪽 탭 **트랙** 클릭: 비디오 **3**, 오디오 트랙 목록에서 **표준(스테레오)** 트랙이 **3개**만 남게 맞춘다(마스터: 스테레오). 여분이 있으면 줄 왼쪽 「−」로 지운다.
4. 맨 아래 **시퀀스 이름**: `영화롱폼` → **확인**.
5. 타임라인이 열리면 왼쪽 트랙 머리글 이름을 바꾼다 — 이름 위에서 **오른쪽 클릭 > 이름 바꾸기**:
   - V1 → `V1 원본컷` · V2 → `V2 대사자막` · V3 → `V3 나레자막`
   - A1 → `A1 원본소리` · A2 → `A2 나레` · A3 → `A3 덕킹소리`
   (프로그램이 이 이름으로 트랙을 찾는다 — 띄어쓰기까지 그대로.)

## 3. 견본 클립 — 원본 컷 1개 (V1 + A1, 링크된 채로)
1. **파일 > 가져오기** → `23. FULL TIME  Omeleto.mp4` 선택 → 열기. 프로젝트 패널에 mp4 항목이 생긴다.
2. 프로젝트 패널의 mp4 를 더블클릭 → 소스 모니터에서 재생 위치를 **00:00:10:00** 근처에 두고 `I`(인 점), 2초 뒤 `O`(아웃 점).
3. 타임라인에서 **V1·A1** 트랙 머리글의 소스 패치(트랙 이름 왼쪽 파란 「V1」「A1」)가 켜져 있는지 확인 → 소스 모니터 아래 **덮어쓰기**(`.` 키) → V1 에 영상, A1 에 소리가 **한 쌍으로** 놓인다. 클립을 클릭하면 둘이 함께 선택되면 정상(링크).
4. 이 컷을 **00:00:00:00** 에 둔다(맨 앞).

## 4. 견본 클립 — 나레 1개 (A2) · 덕킹 소리 1개 (A3)
1. **파일 > 가져오기** → `youstudio_work\fulltime\voice\b01.wav` → 열기.
2. b01.wav 를 프로젝트 패널에서 **A2 트랙의 00:00:00:00** 로 드래그(비디오는 없으니 오디오만 놓인다).
3. 프로젝트 패널의 mp4 를 다시 **A3 트랙 00:00:00:00** 로 드래그하되, 드래그 전에 **V1·V2·V3 소스 패치를 끄고**(트랙 머리글 왼쪽 「V1」 등을 클릭해 회색으로) A3 만 켠 상태에서 놓는다 — 그러면 소리만 A3 에 놓인다. 길이는 3번의 컷과 같은 2초로 잘라도 되고 그대로 두어도 된다.
4. A3 의 그 클립을 클릭 → 창 > **효과 컨트롤** → **볼륨 > 레벨**을 **−12.0 dB** 로 입력(규격 덕킹 레벨). 다른 클립은 0 dB 그대로.

## 5. 자막 견본 2개 — 여기서 위치를 완벽하게 (가장 중요)
**나레 견본 (V3)**
1. 재생 헤드를 00:00:00:00 에 두고, 왼쪽 도구에서 **문자 도구**(T, 단축키 `T`) 선택 → 프로그램 모니터 화면 아무 데나 클릭 → `나레 견본` 이라고 친다 → `Esc`. 그래픽 클립이 **선택된 비디오 트랙**에 생기는데, V3 에 안 생겼으면 클립을 V3 로 드래그해 옮긴다(시작 00:00:00:00, 길이는 그대로 5초).
2. 클립을 선택한 채 창 > **기본 그래픽**(Essential Graphics) > **편집** 탭:
   - 텍스트: 폰트 **Source Han Serif K**(본명조), 스타일 **Bold** · 크기 **96** · 가운데 정렬(가운데 맞춤 아이콘)
   - 모양: 채우기 흰색. 획/그림자는 지무비 스타일이 원하는 대로(있으면 여기서 정한다 — 이후 모든 나레 자막이 이 모양을 따른다)
   - **정렬 및 변형**: 「가로 가운데 정렬」 버튼을 눌러 x 를 가운데로. 위치 y 는 **화면 하단에서 위쪽으로 나레가 자리 잡는 지무비 자리**(1080 기준 y≈840, 화면 아래에서 약 22%)로 두되 **숫자보다 눈**으로: 프로그램 모니터를 「전체 화면」에 가깝게 키우고 지무비 영상을 떠올려 맞춘다.
   - 다 되면 정렬 및 변형의 **위치 값(x, y)을 아래 표에 적는다**(참고용).
**대사 견본 (V2)**
3. 같은 방법으로 문자 도구 → `대사 견본` → V2 로 옮기고, 폰트 **Sandoll 광화문**(SDGwanghwamun) · 크기 **52** · 가운데 정렬 · 흰색, 위치 y ≈ **980**(맨 아래 자막 자리, 나레보다 아래) — 눈으로 맞춘다. 위치 값 기록.
4. 두 견본이 **동시에** 화면에 보이게 하고(둘 다 00:00:00:00 시작) 겹치지 않는지, 나레 위·대사 아래가 자연스러운지 본다.

| 견본 | 폰트 | 크기 | 위치 x | 위치 y | 메모(획/그림자) |
| :---- | :---- | :---- | :---- | :---- | :---- |
| 나레 견본 (V3) | Source Han Serif K Bold | 96 |  |  |  |
| 대사 견본 (V2) | Sandoll 광화문 | 52 |  |  |  |

## 6. 정리 · 저장 · 확인
1. 타임라인에 **위 5개 클립 외 아무것도 없어야** 한다(V1 컷 1 · A1 소리 1 · A2 나레 1 · A3 덕킹 1 · V3 나레 견본 1 · V2 대사 견본 1 = 6개). 시험 삼아 넣은 것이 있으면 지운다. 프로젝트 패널에도 mp4·b01.wav·시퀀스 외 항목이 없어야 한다.
2. **파일 > 저장**(Ctrl+S) → 프리미어 **종료** → 다시 실행해 `도너\영화롱폼_donor_ppro26.3.prproj` 를 열어 6개 클립·폰트·위치가 그대로인지 확인 → 닫는다.
3. 이 파일은 **다시 열어서 편집하지 않는다**(도너는 규격의 일부 — 바꾸려면 새 버전 파일로).
4. 끝나면 클로드에게 "도너 만들었어" + 위 표의 위치 값을 알려 준다. 클로드가 파일을 풀어 오브젝트 수(트랙 6 · 텍스트 클립 2 · 미디어 2)를 세어 계단 2 로 넘어간다.

**막히면**: 폰트 목록에 본명조/광화문이 없다 → 산돌구름을 켜고 프리미어를 재시작. 문자 도구로 친 글자가 안 보인다 → 채우기 색이 검정일 수 있으니 흰색으로. 트랙 이름 바꾸기가 없다 → 트랙 머리글의 이름 글자를 더블클릭.
