# youstudio-mcp — 영화 롱폼 리캡 MCP

영화 한 편을 **롱폼 리캡 영상**으로 만드는 나만의 MCP 서버.
사람이 방향(스타일·규격·판단 기준)을 정하고, 클로드가 서버의 지시대로 실행한다.

구조는 볼케이노 숏폼 파이프라인과 같은 **서버 지휘형**이다 — 규격·명령줄·판단은 전부 서버 쪽에 있고, 클라이언트(runner/클로드)는 서버가 돌려주는 `next_step` 과 지시를 그대로 실행한다. 판단 중 화면을 봐야 하거나 분량이 큰 것은 외부 모델 판정(`judge`)으로 내보내고 결과를 파일로 남긴다.

## 구조 지도

| 위치 | 한 줄 |
| :---- | :---- |
| `HARNESS.md` | 설계 원칙 목차 — 보이지 않으면 없는 것 · 목차형 문서 · 방법이 아닌 조건 · 숫자 반환 · 수리 지침 붙은 게이트 |
| `CLAUDE.md` | 클로드용 운용 규칙 (목차) — 폴더 구조·문서 읽는 규칙·커밋 규칙 |
| `설계/` | 파이프라인 설계 — `단계상세.md`(8단계 명세·게이트) · `단계와게이트.md`(범위·판정 위치·대역 체계) · `외부서비스.md`(외부 API 목록·키 원칙) · `참고_*.md`(참고 파이프라인 분석, 읽기 전용 자료의 요지) |
| `스타일/영화롱폼/` | 스타일 한 벌 — `정답지.json`(게이트 합격 대역, 목표) · `규격.json`(우리가 정한 설정값) · `우리실측.json`(우리 엔진 물성) · `구간선택.md` `나레이션.md` `자막.md`(지침) |
| `서버/` | MCP 서버 (TypeScript · Cloudflare Workers). 도구는 `youstudio_video` 하나. 단계마다 처리기 파일 하나(`src/steps/*.ts`) |

숫자는 `정답지.json`(목표) · `규격.json`(설정) · `우리실측.json`(결과) 세 파일에만 둔다. 게이트가 불통이면 고치는 것은 규격뿐이다.

## 파이프라인 현황

| # | step | 하는 일 | 상태 |
| :---- | :---- | :---- | :---- |
| 0 | `setup` | ffmpeg 확인 · 작업 폴더 · 규격 전달 | ✅ |
| 0 | `start` | 소재 접수 · ffprobe 지시 | ✅ |
| 1 | `probe` | 원본 확인 (길이·해상도·fps·오디오) | ✅ |
| 2 | `transcript` | 오디오 추출 → 전사(**Speechmatics 단어 단위**, Groq 폴백) → 환청 정리 · 무음 실측 | ✅ |
| 3 | `brief` | 전사 전문 → 사건 목록 (외부 판정) | ✅ |
| 4 | `select` | 시각 판정(무음 구간 프레임·결말 클립) + 서버 계산 → 쓸 구간 확정 · 게이트 | ✅ |
| 5 | `script` | 구간을 잇는 나레이션 집필 (대화 안 `need_input`) + 기계 검사 | ✅ |
| 6 | `voice` | TTS(ElevenLabs eleven_v3) · 실측 길이로 슬롯 확정 · 자당초 실측 → 우리실측 · **나레 단어 실측**(이어붙여 1콜) + 문구 대조 | ✅ |
| 7 | `subtitle` | 컷 타임라인 · 대사 번역 · **자막 큐 = 단어 실측 구간**(나레·대사 모두) · 줄 나눔은 집필자 몫 · 무음 컷 · 게이트 12개 | ✅ |
| 8 | `export` | **완성 .prproj**(도너 사본 치환·조립) + FCP XML v5 + SRT 3종 + 나레이션 믹스 + manifest · **최종 재검사 게이트 14개**(1~7 단계 + prproj 자기검증) | ✅ |

첫 시험 소재(단편 15.5분)로 **`setup`~`export` 전 단계**를 실호출까지 통과했다 (마일스톤 `v0.1-select` → `v0.2-script` → `v0.3-voice` → `v0.4-subtitle` → `v0.5-export`). 프리미어 실제 임포트 검증까지 완료(`v0.6-import`: 자막 origin 좌표계·폰트 PS 명·A3 덕킹 트랙·새 빈 프로젝트 규칙). **자막 품질 사이클 완결(2026-08-18, `v0.8-wordsync`)** — 나레·대사 **전체 타이밍이 단어 단위 실측**이다(추정 성분 0). 사용자 검수 7라운드에서 나온 사고를 게이트 11개로 인코딩했다: 교차겹침·자막음성일치·나레문구일치·대사선행·대사커버율·대사잔류·대사원문일치·줄바꿈·나레커버율·나레단어일치·prproj 자기검증. **산출물은 `.prproj`**(열면 전부 제자리, 볼케이노 방식) — 계단 0~4 를 사람 확인과 함께 밟아 `v0.7-prproj` 로 완주했다(`설계/prproj생성_설계안.md`). 조립기는 `서버/runner/조립_prproj.py`, 규격 「조립.산출물」을 `xml` 로 바꾸면 FCP XML 폴백. 2차 목표 `render`(완성 mp4).
