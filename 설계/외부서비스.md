# 외부서비스.md — 앞으로 쓸 외부 API 목록

> 우리 파이프라인이 밖에 부탁하는 것들. 어느 단계가 무엇을 어느 키로 쓰는지 한 곳에 둔다.
> 값(모델·보이스·설정)은 `스타일/영화롱폼/규격.json` 에, 호출 규약은 `참고_runner.md` 에. 여기는 **목록과 결정할 것**만.

## 공통 원칙

- **키는 전부 Windows 사용자 환경변수만.** 파일에 쓰지 않는다. (`[Environment]::SetEnvironmentVariable('<이름>','<키>','User')` — 새 터미널부터 보인다)
- **서버 무보관.** 서버 응답의 `auth` 는 `{env:"<환경변수 이름>"}` 으로 위치만 지시하고, runner 가 로컬에서 읽어 헤더에 붙인다. 응답·payload·로그·파일에 키 값이 나오면 안 된다.
- **커밋 전 키 검색 0건 확인.** 저장소(추적·비추적)와 작업 폴더에서 키 문자열을 찾아 0건이어야 커밋한다.
- **계정은 각자 발급이 원칙.** 가족 키를 쓸 경우 청구가 그쪽으로 가므로 **사전 합의** 필요. 어느 계정 키인지 아래 표에 적는다.

## TTS 를 정할 때 반드시

★ **보이스를 정하면 나레이션 길이·호흡이 달라진다.** 그러므로 TTS 관련 대역(자당 초·문장당 길이·블록 사이 숨 등)은 정답지를 그대로 못 쓰고 **우리실측.json 으로 다시 재야 한다.** 근거: 가족 파이프라인 README — TTS 실측 길이(`char_end`)가 곧 타임라인 슬롯이며(measure-never-predict), 보이스가 바뀌면 그 실측이 전부 바뀐다. `단계와게이트.md` 「우리가 재야 할 것」 참조.

## 이 파일을 고칠 때

- 서비스를 새로 붙이면 표에 한 줄 추가하고, 키 이름을 여기서 먼저 정한다 (코드가 이 이름을 쓴다).
- 상태가 바뀌면(대기 → 사용중) 날짜와 첫 실호출 결과를 한 줄 적는다.

## 전사 제공자 교체 (2026-08-17, 사용자 결정)

### 왜 바꿨나 — 교체 전 실측 (2026-08-17)

Groq whisper 는 **문장 덩어리(세그먼트) 단위** 시각만 준다. 그래서 대사 자막이 **말보다 먼저** 떴다 — 같은 소재(Full Time)에서 잰 값:

| 항목 | Groq 세그먼트 | Speechmatics 단어 |
| :---- | :---- | :---- |
| 대사 큐 선행(자막이 말보다 먼저 뜬 시간) 평균 | **0.393s** | **−0.034s**(말보다 살짝 뒤) |
| 최대 | **2.672s** (`d102 「월급 30% 올려 줄게요」`) | **0.000s** |
| 허용치(0.1s) 초과 | **82건** / 113 | **0건** |

세그먼트 방식의 **구조적 한계**다(한 덩어리의 시작을 그 안 모든 말의 시작으로 쓰니 앞말이 늦게 나올수록 자막이 앞선다). 사용자 판정: **"정확도가 비교가 안 된다"** → 교체 결정, HARNESS 강제 규칙으로 승격(대사 타이밍은 단어 단위 실측, 세그먼트 추정 금지).

- **1순위 Speechmatics** — 단어 단위 시각. 대사 자막의 시작·끝을 **그 말의 첫/마지막 단어**에 맞춘다(게이트 `G-대사선행`).
- **2순위 Groq whisper** — 폴백. 세그먼트 단위라 자막이 말보다 먼저 뜰 수 있다.
- 호출 방식(배치 v2): ① `POST /v2/jobs` (multipart: `data_file` + `config` JSON) → `id` ② `GET /v2/jobs/{id}` 상태가 `done` 이 될 때까지 폴링 ③ `GET /v2/jobs/{id}/transcript?format=json-v2` → `results[]` 의 `start_time·end_time·alternatives[0].content`. 인증 `Authorization: Bearer <SPEECHMATICS_API_KEY>` — **서버는 키를 보관하지 않는다**(env 이름만 지시).
- **첫 실행 실측 (2026-08-17, Full Time)**: 오디오 **929초(15.5분)** · job `eg92of1268` · **제출→done 16초**(폴링 10초 간격이라 실제 처리는 그보다 짧다) · **단어 943개** · 발화 242건 · 응답 `job.duration 929` (청구 단위 = 오디오 분). 언어팩 English, operating_point enhanced, itn 켜짐. 키는 사용자 환경변수 `SPEECHMATICS_API_KEY`(2026-08-17 저장).
  - **요금은 계정 대시보드에서 확인해야 한다** — 응답에 금액이 없다. 15.5분 1건 소비 기록만 남았다.
  - ⚠ 키가 대화창에 평문으로 한 번 노출됐다(2026-08-17). **키 교체(rotate)를 권한다** — 교체하면 같은 방법으로 다시 저장하면 된다.
