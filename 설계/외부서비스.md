# 외부서비스.md — 앞으로 쓸 외부 API 목록

> 우리 파이프라인이 밖에 부탁하는 것들. 어느 단계가 무엇을 어느 키로 쓰는지 한 곳에 둔다.
> 값(모델·보이스·설정)은 `스타일/영화롱폼/규격.json` 에, 호출 규약은 `참고_runner.md` 에. 여기는 **목록과 결정할 것**만.

## 공통 원칙

- **키는 전부 Windows 사용자 환경변수만.** 파일에 쓰지 않는다. (`[Environment]::SetEnvironmentVariable('<이름>','<키>','User')` — 새 터미널부터 보인다)
- **서버 무보관.** 서버 응답의 `auth` 는 `{env:"<환경변수 이름>"}` 으로 위치만 지시하고, runner 가 로컬에서 읽어 헤더에 붙인다. 응답·payload·로그·파일에 키 값이 나오면 안 된다.
- **커밋 전 키 검색 0건 확인.** 저장소(추적·비추적)와 작업 폴더에서 키 문자열을 찾아 0건이어야 커밋한다.
- **계정은 각자 발급이 원칙.** 가족 키를 쓸 경우 청구가 그쪽으로 가므로 **사전 합의** 필요. 어느 계정 키인지 아래 표에 적는다.

## TTS 를 정할 때 반드시

★ **보이스를 정하면 나레이션 길이·호흡이 달라진다.** 그러므로 TTS 관련 대역(자당 초·문장당 길이·블록 사이 숨 등)은 정답지를 그대로 못 쓰고 **우리실측.json 으로 다시 재야 한다.** 근거: 가족 파이프라인 README — TTS 실측 길이(`char_end`)가 곧 타임라인 슬롯이며(measure-never-predict), 보이스가 바뀌면 그 실측이 전부 바뀐다. `단계와게이트.md` 「우리가 재야 할 것」 참조.

## 배포 전 보안 체크리스트 (강제 — HARNESS 규칙)

**배포 = 이 서버를 클라우드에 올리거나, 지인에게 넘기거나, 내 PC 밖에서 돌리는 모든 경우.** 그 전에 아래를 **전부** 통과해야 한다. 하나라도 미완이면 배포하지 않는다.

### 1) 키 전량 재발급 (예외 없음)

| 서비스 | 환경변수 | 재발급 | 재저장(setx) | 이전 키 폐기 확인 |
| :---- | :---- | :---- | :---- | :---- |
| ElevenLabs | `ELEVENLABS_API_KEY` | ☐ | ☐ | ☐ |
| Groq | `GROQ_API_KEY` | ☐ | ☐ | ☐ |
| Speechmatics | `SPEECHMATICS_API_KEY` | ☐ | ☐ | ☐ |
| EvoLink | `EVOLINK_API_KEY` | ☐ | ☐ | ☐ |
| Google Gemini(순정) | `GEMINI_API_KEY` | ☐ | ☐ | ☐ |
| (그 밖에 표 「목록」에 추가된 키 전부) | — | ☐ | ☐ | ☐ |

재저장: `[Environment]::SetEnvironmentVariable('<이름>','<새 키>','User')` — **값은 화면에 남기지 않는다**. 폐기 확인 = 각 서비스 대시보드에서 옛 키가 **삭제/비활성**인지 눈으로 본다(옛 키로 한 번 호출해 401 을 확인하면 더 확실하다).

### 2) 저장소·작업 폴더 키 검색 0건

커밋 규칙과 같다 — 저장소(추적·비추적)와 `youstudio_work/` 에서 각 키 앞 8자를 찾아 **0건**이어야 한다. 배포 직전 한 번 더 돌린다.

### 3) 평문 노출 이력 — 이 표가 "무효화됨"을 보증한다

| 언제 | 어디에 | 무엇이 | 상태 |
| :---- | :---- | :---- | :---- |
| ~2026-08-15 | claude.ai 채팅 | `GROQ_API_KEY` | **재발급 대상** |
| ~2026-08-15 | claude.ai 채팅 | `EVOLINK_API_KEY` | **재발급 대상** |
| 2026-08-17 | Claude Code 대화(이 저장소 세션 로그) | `SPEECHMATICS_API_KEY` | **재발급 대상** |
| (추가되면 여기에 한 줄) | | | |

노출된 키는 **배포 전 재발급으로 전부 무효화**된다. 새 키는 **어떤 대화창에도 붙여넣지 않는다** — 터미널에서 위 명령으로만 저장한다.

### 4) 서버 쪽 인증 (배포 시 설정할 것 — 자리만 만들어 둠)

| 항목 | 정할 것 | 상태 |

| 전송 | HTTPS 강제 · 리다이렉트 금지 | ☐ 미정 |
| 로그 | 요청 본문에 키·개인정보가 남지 않는지 | ☐ 미정 |
| 키 저장 위치 | 클라우드에서는 환경변수가 아니라 시크릿 저장소(예: Workers Secrets) — **서버 무보관 원칙과 어떻게 맞출지** 결정 | ☐ 미정 |

## 전사 제공자 교체 (2026-08-17, 사용자 결정)

### 왜 바꿨나 — 교체 전 실측 (2026-08-17)

Groq whisper 는 **문장 덩어리(세그먼트) 단위** 시각만 준다. 그래서 대사 자막이 **말보다 먼저** 떴다 — 같은 소재(Full Time)에서 잰 값:

| 항목 | Groq 세그먼트 | Speechmatics 단어 |
| :---- | :---- | :---- |
| 대사 큐 선행(자막이 말보다 먼저 뜬 시간) 평균 | **0.393s** | **−0.034s**(말보다 살짝 뒤) |
| 최대 | **2.672s** (`d102 「월급 30% 올려 줄게요」`) | **0.000s** |
| 허용치(0.1s) 초과 | **82건** / 113 | **0건** |

세그먼트 방식의 **구조적 한계**다(한 덩어리의 시작을 그 안 모든 말의 시작으로 쓰니 앞말이 늦게 나올수록 자막이 앞선다). 사용자 판정: **"정확도가 비교가 안 된다"** → 교체 결정, HARNESS 강제 규칙으로 승격(대사 타이밍은 단어 단위 실측, 세그먼트 추정 금지).

- **1순위 Speechmatics** — 단어 단위 시각. 대사 자막의 시작·끝을 **그 말의 첫/마지막 단어**에 맞춘다(게이트 `G-대사선행`).
- **2순위 Groq whisper** — 폴백. 세그먼트 단위라 자막이 말보다 먼저 뜰 수 있다.
- 호출 방식(배치 v2): ① `POST /v2/jobs` (multipart: `data_file` + `config` JSON) → `id` ② `GET /v2/jobs/{id}` 상태가 `done` 이 될 때까지 폴링 ③ `GET /v2/jobs/{id}/transcript?format=json-v2` → `results[]` 의 `start_time·end_time·alternatives[0].content`. 인증 `Authorization: Bearer <SPEECHMATICS_API_KEY>` — **서버는 키를 보관하지 않는다**(env 이름만 지시).
- **첫 실행 실측 (2026-08-17, Full Time)**: 오디오 **929초(15.5분)** · job `eg92of1268` · **제출→done 16초**(폴링 10초 간격이라 실제 처리는 그보다 짧다) · **단어 943개** · 발화 242건 · 응답 `job.duration 929` (청구 단위 = 오디오 분). 언어팩 English, operating_point enhanced, itn 켜짐. 키는 사용자 환경변수 `SPEECHMATICS_API_KEY`(2026-08-17 저장).
  - **요금은 계정 대시보드에서 확인해야 한다** — 응답에 금액이 없다. 15.5분 1건 소비 기록만 남았다.
  - ⚠ 키가 대화창에 평문으로 한 번 노출됐다(2026-08-17). **키 교체(rotate)를 권한다** — 교체하면 같은 방법으로 다시 저장하면 된다.

## 제미나이 영상 판독 — 유튜브 URL 입력 실측 (2026-08-18)

분석 단계 (b) 자동화를 위한 탐침(`서버/runner/분석_탐침.mjs`) 결과.

| 경로 | 결과 | 원문 요지 |
| :-- | :-- | :-- |
| **EvoLink** `v1beta/{model}:generateContent` + `file_data.file_uri = 유튜브 URL` | **된다(HTTP 200)** — 영상을 실제로 보고 답한다 | 단 **`mime_type` 이 비면 400**: "empty mimeType parameter in fileData" → `video/mp4` 를 붙인다 |
| 구글 순정 `generativelanguage.googleapis.com` | **429** | "Your prepayment credits are depleted" — 선불 크레딧 소진. 무료 티어 경로가 아니다. **폴백으로만** 남긴다 |
| Python `urllib` 기본 호출 | **403 code 1010** | Cloudflare 가 `Python-urllib` UA 를 막는다 → 보통 UA 를 붙이면 통과 |

**비용·시간 실측** (모델 `gemini-3.5-flash` · 8.5분 영상 1편 · 판독 프롬프트 2,717자)

| 항목 | 실측 |
| :-- | :-- |
| 걸린 시간 | **51.3초**(짧은 탐침은 26.4초) |
| 프롬프트 토큰 | **215,927** — VIDEO 153,318 · AUDIO 58,083 · TEXT 나머지 |
| 분당 토큰 | **약 25,000 토큰/영상 1분** ← 비용을 이 값으로 추산한다 |
| 10편 추산 | 편당 8~15분이면 **총 2.0~3.8M 토큰**, 시간 **9~15분** |

요금은 EvoLink 대시보드에서 확인한다(토큰 단가는 우리가 모른다). **재판독은 돈이다** — 프롬프트를 고치면 10편을 다시 돌려야 하므로, 1편으로 품질을 확인한 뒤 확장한다.

### 10편 판독 실측 합계 (2026-08-18)

| 항목 | 실측 |
| :-- | :-- |
| 호출 | **10건**(편당 1콜, 유튜브 URL 직접 입력) |
| 토큰 | **1,503,355**(편당 71K~250K · 영상 길이에 비례) |
