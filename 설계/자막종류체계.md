# 자막 크기 실패 — 진단과 자막 종류 체계 설계안 (2026-08-20)

지시: ① 축을 잘못 맞춘 것 ② 자막을 2종으로 뭉갠 것, 두 가지를 함께 고친다. **진단·설계만, 반영은 승인 후.**

결론 먼저 — **도너 원본 값이 이미 정답이었다.** 우리는 잘못된 자로 재서 나레를 절반으로 줄였다.

| | 대사 | 나레 |
| :-- | :-- | :-- |
| 지무비 실측(같은 자) | **4.91%** | **10.56%** |
| 도너 원본(볼케이노 완성본) | **5.00%** (58px) | **8.8~10.7%** (120px) |
| **우리 2판(지금)** | **3.8%** (44px) | **5.7%** (64px) |

---

## 1. 무엇이 잘못됐나 — 두 축을 같은 값으로 봤다

| 축 | 뜻 | 누가 쓰나 |
| :-- | :-- | :-- |
| **글꼴 크기(px)** | 폰트의 **em 상자** 설정값 | 프리미어 기본 그래픽 · 우리 규격 `자막.크기_px` |
| **잉크 높이(%)** | 화면에 실제로 **찍힌 글자**의 위아래 길이 ÷ 1080 | 우리 계측기(레퍼런스 해부) · 정답지 `글자높이_화면대비_%` |

둘은 **비례하지만 같지 않다.** 변환비(잉크 ÷ 설정)를 폰트별로 실측했다.

| 재는 법 | 폰트 | 변환비 |
| :-- | :-- | :-- |
| **폰트 파일 직접 렌더**(가진 폰트) | Noto Sans KR 0.89 · 맑은 고딕 0.96 · 바탕 0.93 · Cafe24 Ohsquare 0.90 | **0.88~0.97** |
| **도너 영상 실측**(실제 쓰는 폰트) | SDGwanghwamun 0.92 · SourceHanSerifK-Bold 0.96 · SDKwangya 0.78~0.94 · SDGdMyeongjo 0.76~0.95 · **Cafe24Dangdanghae 0.68** | **0.68~0.97** |

**폰트마다 다르고, 같은 폰트라도 글자에 따라 다르다**(받침·문장부호 유무). 그래서 「4.07% 니까 44px」 같은 환산은 성립하지 않는다.
사고의 실제 경로: 정답지에 **잉크 %**로 적힌 목표(2.6~5.9%)를 프리미어 **글꼴 크기**로 그대로 옮겨 적었다 → 나레 120px → 64px, 대사 58px → 44px.

## 2. 실측 ② — 도너 자막 136개를 종류로 갈랐다

기준: 트랙 · 폰트 · 글꼴 크기 · 런 구성(prproj) + 잉크 높이 · 색(렌더 영상). **28가지 조합**이 나왔고, 트랙이 곧 종류였다.

| 트랙 | 개수 | 폰트 | 설정 px | **잉크 %** | 색 | 한 줄에 색 둘 | 추정 쓰임 · 근거 |
| :-- | --: | :-- | :-- | --: | :-- | --: | :-- |
| **V2** | 79 | SDGwanghwamun **1종** | **58 고정** | **5.00** | 흰 78/78 | **0**개 | **인물 대사** — 폰트·크기가 하나로 고정, 길이 평균 1.78s, 글이 전부 대사체(「돈 준다면 할 거야?」) |
| **V3** | 34 | 본명조 Bold 15 · Cafe24당당해 17 · 기타 2 | 82~153 | **8.80**(본명조 120px는 10.74) | 흰 29 · 노랑 1 · 빨강 1 | **17**개 | **나레이션** — 서술체(「자리를 지킨..」), 런이 2~3개로 나뉜다 |
| **V4** | 23 | **8종 전부 다름** | 97~174 | **10.46** | 흰 11 · 빨강 6 · 노랑 4 · 초록 1 | **14**개 | **소제목·전환 문구** — 같은 조합이 두 번 안 나온다, 「대학 졸업식 날」·「직업 정신 하나로」·「지금까지 Full Time였습니다」 |

**읽히는 것**
- **대사는 규격품**이다 — 한 벌만 있으면 된다.
- **나레는 두 벌**이다 — 본명조 Bold 120px(잉크 10.7%)가 본체, Cafe24당당해 117px(잉크 7.3%)가 다른 톤. 같은 트랙에 섞여 있다.
- **V4는 매번 새로 만든 장식**이다 — 규격화 대상이 아니라 「골라 쓰는 서랍」에 가깝다.
- **한 줄에 색이 둘인 큐가 31개**(V3 17 · V4 14) — 도너에 **단어 강조가 실제로 있다**(§6).

## 3. 실측 ③ — 지무비 10편을 **같은 자로** 다시 쟀다

옛 계측(레인 두께)이 아니라 **도너와 똑같은 자**로 쟀다: 밝거나 물든 픽셀 + **검은 테두리** + **0.2초 뒤에도 그대로**(전환 효과 제외). 편당 프레임 30개 표본, 프레임마다 주 자막 줄 1개.

| 무리 | 줄 수 | 잉크 % (p25~p75) | 중앙 | 잉크 아랫변 | 주색 |
| :-- | --: | :-- | --: | :-- | :-- |
| **작은 자막** | 129 (68%) | 4.63~5.09 | **4.91%** | 90.9% | 흰 118 · 노랑 8 |
| **큰 자막** | 60 (32%) | 9.35~11.30 | **10.56%** | 91.2% | 흰 34 · **빨강 20** · 노랑 4 |

**10편이 전부 같은 구조다** — 작은 쪽 4.63~5.09, 큰 쪽 9.90~11.57. 한 편도 예외가 없다.
그리고 **두 무리의 잉크 아랫변이 같다(91%)** — 즉 레퍼런스는 **글자 아랫변을 한 자리에 맞추고**, 크기가 커지면 위로 자란다.
**한 줄 안에 색이 둘 이상인 줄이 30%** — 강조는 예외가 아니라 일상이다. 빨강 중앙값 **#E60206**(도너는 #D60009).

| | 지무비(재계측) | 도너 원본 | **우리 2판(지금)** | 판정 |
| :-- | :-- | :-- | :-- | :-- |
| 대사 | **4.91%** (4.63~5.09) | **5.00%** (58px) | **3.8%** (44px) | 우리만 **23% 작다** |
| 나레 | **10.56%** (9.35~11.30) | **10.74%** (본명조 120px) | **5.7%** (64px) | 우리만 **거의 절반** |
| 소제목 | 큰 무리 상단 ~13% | **10.46%** (V4 중앙) | 없음 | 종류 자체가 없다 |
| 잉크 아랫변 | 91% | V2 96.4% · V3 97.7% | 중심 86.3% | 축이 서로 다르다 |

**도너 원본은 이미 지무비 대역 안에 있었다.** 우리가 유일하게 벗어났다.

## 5. 왜 옛 계측이 4.07% 라고 했나

옛 계측은 **레인 검출**이었다 — 한 초씩 훑어 「잉크가 자주 나오는 행 띠」의 두께를 쟀다. 그 띠는 **자주 나오는 부분**만 잡히므로 글자 전체 높이보다 얇게 나온다(작은 자막이 대부분이라 큰 자막은 묻힌다). 게다가 표본이 8편이었다.
이번 자는 **한 큐의 글자 한 줄**을 통째로 잰다. 두 자는 이름만 같고 재는 대상이 다르다.
**증거**: 정답지에 남아 있던 가족 실측(G34) — 나레 95~108px · 대사 49~55px · 나레 강조 106~126px — 이 이번 재계측(작은 53px · 큰 114px)과 **거의 일치**한다. 우리는 맞는 값을 틀린 값으로 덮어썼던 것이다.

## 6. 부수 소득 — **강조는 블롭 안에 있다**(진단일지 §23 확정)

렌더 영상에서 **한 줄에 색이 둘인 도너 큐 31개**를 찾았다. 그중 §23에서 지목한 바로 그 큐가 있다:

```
V3 item 4076 · 런 3 · 흰 76% + 빨강 24% · 「마이클은 본격적인 / 감금 근무 / 를 시작하고..」
V4 item 4049 · 런 2 · 빨강 59% + 흰 41% · 「이 말도 안 되는 제안을 수락하며..」
```

**런이 강조 단어 경계에서 나뉘고, 화면에서 그 단어만 빨강이다.** 우리 파서가 색을 [0,0,0]으로 읽는 것은 파서의 한계다.
→ 바이트 대조 대상이 **31개 큐로 특정**됐다. 5단계(단어 강조)는 「새로 쓰기」가 아니라 「이 큐들에서 차이 나는 바이트를 찾아 복제」가 맞다.

## 7. 설계안 — 자막을 **종류 체계**로 바꾼다

### 지금 구조(단일 값)와 무엇이 다른가

```
지금:  자막.크기_px = {나레: 64, 대사: 44}      ← 종류가 둘, 강조 개념 없음, 색 없음
바꿈:  자막.종류 = { 대사, 대사_강조, 나레, 나레_강조, 소제목 }
         종류마다 → 견본(도너의 어느 큐) · 폰트 · 글꼴 px · 목표 잉크 % · 색 · 강조 배수
```

### 종류 정의안

| 종류 | 쓰임 | 폰트 | 목표 잉크 % | 색 | 견본(도너) |
| :-- | :-- | :-- | --: | :-- | :-- |
| `대사` | 인물이 말하는 것 | SDGwanghwamun | 4.9 | 흰 | V2 큐(78개 중 아무거나) |
| `대사_강조` | 대사 안에서 힘주는 말 | 〃 | 4.9(같음) | **빨강 #E60206** | 색 대조로 특정할 큐 |
| `나레` | 서술 | 본명조 Bold | 10.6 | 흰 | V3 본명조 120px 큐 10개 |
| `나레_강조` | 서술 안 핵심 단어 | 〃 | 10.6(같음) | **빨강** | V3 두 색 큐 17개 |
| `소제목` | 장면 전환·마무리 문구 | 서랍에서 고름(8종) | 10.5~14 | 다양 | V4 큐 22개 |

**강조는 크기가 아니라 색이다**(도너 실측: 강조 런의 글꼴 크기가 본문과 **같다**). 제미나이 판독의 「1.2~1.3배」는 눈대중이므로 **채택하지 않고**, 색만 먼저 도입한다.

### 정답지·규격을 어떻게 나눌 것인가

| 파일 | 무엇을 담나 |
| :-- | :-- |
| **정답지**(목표) | 종류별 **잉크 % 대역**(지무비 실측) · 강조 색 · 강조 비율 대역 · 잉크 아랫변 위치 |
| **규격**(설정) | 종류별 **견본 지정**(트랙·폰트·크기로 찾는다) · 글꼴 px · 폰트 이름 · 색 |
| **우리실측**(결과) | 우리가 만든 영상의 종류별 잉크 % — 정답지와 나란히 본다 |

**핵심**: 규격에는 **글꼴 px**를, 정답지에는 **잉크 %**를 둔다. 둘을 잇는 것은 **폰트별 변환비**(§1 표)이고, 이 표는 우리실측에 둔다. 축을 섞지 않는 유일한 방법이다.

### 게이트

- `G-자막_잉크높이` — 완성본에서 종류별 잉크 %가 정답지 대역 안인가(자막_실측.py 로 잰다). **수리 지침**: 벗어나면 규격 글꼴 px 를 변환비로 되계산.
- `G-자막_한줄_최대자수` — 글꼴 px 가 바뀌면 **같이 다시 계산**한다(지금 값 나레 24 · 대사 34는 64/44px 기준이라 무효).

## 8. 새 값 후보 — 종류별 세 안

변환비는 도너 실측값(SDGwanghwamun 0.92 · 본명조 0.96)을 쓴다. `글꼴 px = 잉크% × 1080 ÷ 100 ÷ 변환비`

| 종류 | | **하한** | **중앙(권고)** | **상한** |
| :-- | :-- | --: | --: | --: |
| **대사** | 잉크 % | 4.4 | **4.9** | 5.4 |
| | 글꼴 px | 52 | **58** | 63 |
| | 근거 | 지무비 p25 4.63 아래 | **지무비 중앙 4.91 · 도너 58px = 5.00%** | 지무비 p75 5.09 위 |
| **나레** | 잉크 % | 9.4 | **10.6** | 11.5 |
| | 글꼴 px | 106 | **119** | 129 |
| | 근거 | 지무비 p25 9.35 | **지무비 중앙 10.56 · 도너 120px = 10.74%** | 지무비 p75 11.30 |
| **소제목** | 잉크 % | 10.5 | **12.5** | 14.5 |
| | 글꼴 px | 126 | **150** | 174 |
| | 근거 | V4 하단 | V4 중앙~상단 | V4 최대(174px) |

**권고는 중앙안** — 지무비 중앙값과 도너 원본이 **거의 같은 자리**이고, 도너 원본은 사람이 이미 만족한 결과다.
한 줄 최대 자수는 중앙안 기준으로 **나레 13자 · 대사 28자** 근처가 된다(폭 = 화면 폭 × 0.86 ÷ 글꼴 px). 이 값은 반영할 때 다시 계산한다 — **자수 상한이 크게 줄어드는 것이 이 안의 가장 큰 파급**이다.

## 9. 반영 방법 — 도너 견본을 여러 개 쓴다

이미 확인된 부산물: 조립기는 **견본을 속성으로 찾는다**(폰트·트랙). 종류를 늘리는 것은 **견본을 더 지정하는 일**이지 새 코드가 아니다.

| 단계 | 무엇 | 누가 |
| :-- | :-- | :-- |
| 1 | 도너_2판의 견본 2개를 **중앙안 값으로 되돌린다**(나레 64→119px · 대사 44→58px) | 사람(프리미어, 10분) |
| 2 | `소제목` 견본을 V4 큐 중 하나로 지정 | 클로드(규격) |
| 3 | 조립기가 `종류` 를 보고 견본을 고르게 한다(지금은 lane 두 갈래) | 클로드 |
| 4 | 자수 상한 재계산 → 줄 나눔 소급 | 클로드 |
| 5 | 완성본을 `자막_실측.py` 로 재서 정답지 대역 안인지 확인 | 클로드 |
| 6 | 강조(색)는 **바이트 대조 뒤** — 31개 큐가 후보로 특정됐다 | 클로드 |

**레인**: 지무비는 **잉크 아랫변 91%** 로 맞춘다(크기가 달라도 아랫변이 같다). 우리 현재 규격은 **중심**을 932px 로 맞춘다 — 종류마다 크기가 다르면 아랫변이 들쭉날쭉해진다. 아랫변 정렬로 바꿀지는 **결정할 것**(§11).

## 10. 하지 않을 것

- **제미나이 눈대중 1.2배 배수**를 크기 규격에 쓰지 않는다 — 도너 실측은 강조 런의 크기가 본문과 같다.
- **레인 검출 기반 옛 대역**(2.6~5.9%)을 되살리지 않는다 — 재는 대상이 다른 자다(정답지에 무효 표시).
- V4(소제목) 폰트 8종을 그대로 베끼지 않는다 — 우리 채널 톤은 따로 정한다.

## 11. 승인받을 것 (반영 전)

1. **세 안 중 어느 것** — 권고는 **중앙안**(나레 119px · 대사 58px · 소제목 150px).
2. **레인 기준**: ⓐ 지금처럼 중심 932px 유지 · ⓑ **잉크 아랫변 91%(983px) 정렬**(지무비 방식).
3. **소제목 종류를 지금 도입할지**, 아니면 대사·나레 두 종류만 먼저 고칠지.
4. 자수 상한이 나레 24 → 13자 근처로 줄어드는데, **줄 나눔 소급**(대본 재집필 없음, 음성 재합성 없음)을 함께 할지.
