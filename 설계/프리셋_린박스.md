# 프리셋 3호 — 린박스 (볼케이노 → 유스튜디오 이식) 설계안 · 초안

> 상태: 초안 2026-09-03(사장님윈도우) → **2026-09-04 2절 단계 확정 + styles.ts 등록(맥2)**. 처리기(lb_*)는 미구현(stub). 선행 전제(키트 합치기)는 2026-09-03 승격으로 끝남(취사병 재현은 볼케이노 쪽 확정용).
> 본뜬 틀: `설계/프리셋_스케치코미디.md` (프리셋 2호). 그 흐름을 린박스에 맞춰 편다.

## 왜 이식하나 (사장님 2026-09-03)

- **권한**: 볼케이노 MCP 는 지인 PC 에서 로그인·권한으로 막히는 경우가 있다.
- **소유권**: 볼케이노는 사장님 MCP 가 아니라 프리셋을 마음대로 못 붙인다. 유스튜디오는 사장님 소유(`youstudio-mcp` · 사장님 Cloudflare)라 자유롭게 붙이고 지인에게 열어준다.
- 따라서 볼케이노 린박스는 **내부 작업용으로 그대로 두고**, 유스튜디오에 린박스 프리셋을 새로 만들어 **지인·외부 배포용**으로 쓴다. 같은 이름 두 벌이지만 역할이 갈린다(내부 vs 외부). 메모리 [[youstudio-is-home-mcp]].

## ★선행 전제 — 이게 끝나야 이식 시작 (지금 진행 중)

**볼케이노 린박스 키트가 하나로 합쳐진 뒤에** 이식한다. 갈라진 상태로 이식하면 반쪽만 간다.
- 키트 두 갈래(사장님판 볼트 `스크립트/린박스/키트/` · 직원판 `A:_배포키트`)를 파일 단위로 합치는 중.
  NAS zip(`린박스_배포키트_윈도우_20260903.zip`) 도착, jsx 세 판은 2026-09-03 합쳐 승격.
  나머지 도구 합치기는 맥2 몫 (제안 `린박스키트_볼트가_일주일_뒤처짐`).
- 합쳐진 볼트 키트 = 이식 **원본**. 그 전엔 아래 단계·값이 확정 안 된다.

## 1. 무엇을 만드나 — 소재 → 산출물

- **소재**: 드라마·영화 한 편(로컬 mp4 또는 링크). 볼케이노 린박스와 같은 입력.
- **산출물**: 린박스 규격 숏폼 **1080x1920 · 60fps · 40~60초** mp4 (+ 프리미어 `.prproj` + SRT).
  ※ 볼케이노 린박스 완성 검사 10항목 + prproj 11번(마스터 브로드캐스트 −3dB)을 그대로 게이트로.
- 볼케이노와 다른 점: 서버가 사장님 것이라 **지인 PC 에서 러너만으로 돈다**(볼트 없이 — 규격은 서버 번들에).

## 2. 단계 — 볼케이노 린박스 흐름을 MCP step 으로 편다 (★2026-09-04 확정 · 맥2)

스케치코미디가 `sk_*`, 영화롱폼이 접두 없는 단계를 쓰듯, 린박스는 **`lb_*`** 를 쓴다.
정본은 5.5절대로 **맥 사슬**(`신병4/한번에.sh`)이다. 합쳐 승격한 키트(2026-09-03)의 `한편.py`·`한번에.sh`·`완성검사.sh`·`프리미어내기.py` 를 읽어 확정했다 — 실측 근거는 `스타일/린박스/STYLE.md` 「제작 단계」 표.

## 3. 선행 작업 — 파이프라인 등록표

스케치코미디 때 이미 **등록표 전환은 완료**(styles.ts steps 가 정본). 린박스는 STYLES 에 한 줄 추가만:
```
린박스: { spec, answer, guideMd, from, steps: [...lb_*...], workDirs: [...] }
```
그러면 schema enum·next_step·처리기 지도(PIPELINES)가 자동으로 린박스를 받는다. 영화롱폼 상수 import 는 그 파이프라인 전용이라 안 건드린다(스케치 때 원칙).

## 4. 코드·자산 이식 (합쳐진 볼트 키트 → 저장소)

- `서버/runner/린박스/` 에 키트 도구 반입 (경로는 인자로, `A:\`·`C:\Users` 절대경로 0곳 — 이미 그렇다고 제안서 grep 확인).
- config 3파일: `스타일/린박스/규격.json`(서버 기본값) · `정답지.json`(게이트 대역) · 지침 md.
  → 볼케이노 카드 `프리셋/린박스.md` + 작품 카드에서 **채널 공통 값만** 규격으로. 작품별은 편정보로.
- 자산(글꼴·아모르 부품·곳간·sfx)은 `.gitignore` 예외로 `자산/린박스/`. 소리·부품은 볼트 밖이니 NAS/저장소 정책 따름.

### 맥/윈도우 이식 주의
- 원본 키트는 윈도우·맥 양쪽에서 자랐다. 글꼴 사다리·경로 분기는 스케치 `s2pipe/cfg.py` 방식(공용 로더) 따름.

## 5.5 정본 경로 = 맥 사슬 (사장님 2026-09-04 확정)

린박스 키트엔 제작 경로가 둘이다 — 서버 사슬(취사병식·자동)과 맥 사슬(신병4식·프리미어 정밀편집).
**유스튜디오 린박스는 맥 사슬을 정본으로 한다.** 손이 더 가도 정확한 길을 간다(사장님 방침 — 돌아가더라도 정확·정직·올바른 길).
- 맥 사슬 = `신병4/한번에.sh` 경로: 서버 ass 받음 → 서식.py → 그래픽·계획 → xml짓기 → 프리미어(잠금) → 곳간서식·자리잡기·꾸미기 → 주입검사·자막자리검사 → 마스터효과심기 → 아모르입히기 → 완성굽기 → _synccheck.
- lb_* 단계는 이 사슬을 편다. 미검증 7파일 중 서버 사슬 전용(make_ass·drv2·render·export_premiere)은 맥 사슬이 안 쓰므로 **린박스 이식엔 안 들어간다** — 취사병 재현은 볼케이노 윈도우 쪽 확정용으로 남고, 유스튜디오 린박스와는 분리된다.
- 다만 프리미어 단계는 지인 PC 에 프리미어·CEP 확장이 있어야 한다 — 지인 배포 요건에 추가(설계 7절).

## 6. 하지 않을 것

- 볼케이노 린박스를 **없애거나 옮기지 않는다** — 내부 작업용으로 유지.
- 갈라진 키트를 합치기 전에 이식 착수하지 않는다.
- 규격을 확장 해석하지 않는다(볼케이노 린박스 값 그대로).

## 7. 배포·권한 정책 (사장님 2026-09-03 확정)

- **볼트 없이** 러너+자산만 지인에게. ✔ 확정.
- ★**정본 = 맥 사슬**(5.5절)이라 지인 PC 에 **프리미어 + CEP 확장(com.volcano.prproj)** 이 필요하다. 설치 꾸러미에 `프리미어깔기.py`(확장·PlayerDebugMode) 를 포함하고, 프리미어 미설치면 그 단계에서 안내. 지인 설치 안내(아티팩트)에도 «프리미어 필요» 한 줄 추가.
- **API 키는 지인이 직접 발급한다** — 사장님 키는 설치 꾸러미에 **절대 포함하지 않는다**. 볼케이노 키 보호 규칙과 동선. 유료 API(Typecast·Speechmatics) 비용도 지인 본인 계정·본인 키. ✔ 확정.
- **필요한 API 안내는 서버가 한다** — 지인이 `setup` 을 부르면 서버가 "이 프리셋에 필요한 키 목록 + 각 발급처 URL"을 돌려준다(프리셋별로 다름). 키 값은 안내만, 서버는 값을 받지 않는다(auth 는 "어디서 읽어라"만 — schema.ts 규약 그대로). ✔ 확정.

### 이메일 허가제 (사장님 지시 — 볼케이노처럼)
