# 가족(볼케이노 제작자) 인터뷰 — 강제 규칙 · 검증된 프로세스 · 물어볼 것

기록일 2026-08-16. 전달받은 내용은 **원문 취지 그대로** 적는다. 해석·설계는 `장면이해_설계안.md` 에서 한다.

## 전달받은 내용 (원문 취지)

**검증된 프로세스는 두 단계다.**
- **① 분석 단계**: 레퍼런스 채널 칼카피 — 대본·자막·스타일을 제미나이 + 클로드로 분석해 **지침서를 고도화**한다.
- **② 구현 단계**: 영상 + 지침서 → **구글 AI Studio 제미나이 멀티모달** → 대본 + 편집점 타임코드 → TTS 나레이션 → 프리미어 자막·컷편집.

**강제 규칙 (가장 중요):**
> 영상 분석은 제미나이 멀티모달이 영상 **"전체"** 를 직접 봐야 한다.
> 클로드 코드는 멀티모달이 안 되어 프레임 추출 방식인데, 이는 **열등한 폴백**이다.
> **제미나이를 붙이는 것이 이 파이프라인의 핵심이다.**

## 우리 현재와의 거리 (사실만)

| 가족 기준 | 우리 지금 (v0.5-export) | 판정 |
| :---- | :---- | :---- |
| 제미나이가 영화 **전체**를 본다 | brief = 전사 **텍스트만** · select = 무음 구간 **프레임 5s 간격 + 결말 클립 15s** 만 인라인 전달 | **미달** — 폴백 방식 |
| 지침서를 영상과 함께 준다 | brief/select 프롬프트에 규격 일부만 | 미달 |
| 제미나이 출력 = 대본 + 편집점 타임코드 | select 는 서버가 우선순위 채움 · script 는 클로드가 대화 안에서 | 다름 (의도적 — 조건만 적고 방법은 클로드) |
| ① 분석 단계(칼카피 → 지침서 고도화) | 정답지.json(지무비 19편 대역) + 나레이션.md/참고_대본지침.md — 한 번 만든 뒤 고도화 루프 없음 | 미달 |

## 인터뷰 질문 (우선순위 순)

- **Q1.** 완성 prproj 는 어떻게 만들어? 미리 만든 틀(donor) prproj 를 복제해서 내용을 바꿔치기하는 방식이야?
- **Q2.** 제미나이에 영상 전체를 어떻게 넣어? (Files API 자동? AI Studio 에 수동 업로드? 지침서는 어느 시점에 같이 줘?)
- **Q3.** 제미나이가 뱉는 출력 형식은? (대본 + 편집점 타임코드가 한 번에? 몇 번에 나눠서?)
- **Q4.** 프리미어프로용 XML 3종은 어떻게 만들었고 각각 용도가 뭐야?
- **Q5.** 분석 단계(레퍼런스 칼카피)는 얼마나 자주 돌려? 지침서 고도화는 어떤 형식으로 쌓여?

답을 받으면 여기 각 질문 밑에 **답 · 날짜**를 적고, 설계에 반영한 것은 해당 문서를 가리킨다.
