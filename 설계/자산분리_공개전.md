# 자산 분리 — 저장소 공개 전 (설계만 · 실행은 사장님 승인 뒤 · 2026-09-04 맥2)

## 왜
저장소를 공개하면 `자산/`(글꼴·효과음·모델 — 저작권물 134개 · 12.7MB)이 **git 히스토리째** 노출된다. 지금 커밋에서 지워도 옛 커밋에 남으므로 히스토리를 다시 써야 완전하다. 길 C(이식원칙 ⑥)에서 자산은 서버(`/asset/<프리셋>/…` · 토큰 인증 · 커밋 7039c60)가 내려주므로 저장소에는 없어도 된다.

## 방법 (권장: git filter-repo)
```
# 0) 되돌아갈 자리 — 통째 복제본을 따로 둔다 (되돌리기 = 이 복제본으로 force-push)
git clone --mirror https://github.com/ujuspace143300/youstudio-mcp.git youstudio-mcp.백업.git
# 1) 자산 원본을 저장소 밖으로 (볼트 `자산/유스튜디오/<프리셋>/` — Obsidian Sync 로 맥1·맥2·윈도우 공유 · 12.7MB)
# 2) 새 클론에서 히스토리 재작성
pip install git-filter-repo
git clone https://github.com/ujuspace143300/youstudio-mcp.git 재작성 && cd 재작성
git filter-repo --path 자산/ --invert-paths        # 자산/ 을 모든 커밋에서 뺀다 (커밋 해시 전부 바뀜)
# 3) .gitignore 에 `자산/` 추가 + 배포.sh 가 볼트 자산을 저장소 자산/ 로 복사(또는 심볼릭 링크)한 뒤 wrangler deploy
# 4) 태그 다시 (v0.1~v0.3 — 해시가 바뀌므로 filter-repo 가 옮겨 준다 · 확인만)
# 5) 원격에 강제 반영: git push --force --all && git push --force --tags
# 6) 맥1·맥2·윈도우 전부 **새로 clone** (옛 클론에서 pull 하면 옛 히스토리가 다시 섞인다)
# 7) GitHub 쪽 캐시: 공개 전환 전에 Support 에 «reachable 아닌 객체 정리» 요청 가능(선택)
```

## 위험 · 지킬 것
- **모든 커밋 해시가 바뀐다** — 문서·메모리·진행상황에 적힌 해시(9228b09 등)는 옛 것이 된다. 태그 이름(v0.3-린박스)은 유지.
- 재작성 뒤 옛 클론에서 push 하면 히스토리가 둘로 갈린다 → 3대 모두 새로 clone 하고 옛 폴더는 이름 바꿔 보관.
- Cloudflare 배포는 영향 없음(코드 내용은 같다). `.last_deploy` 의 해시만 옛 값 → 배포 한 번 더.
- 실행은 **사장님 승인 뒤 사장님 컴퓨터(owner)에서** — 저장소·배포는 사장님 컴퓨터 몫(작업규칙 「역할」).
- 공개 전환은 사장님이 GitHub 에서 직접(윈도우 비밀검사 완료 상태 유지 — 재작성 뒤 `git log -p | grep -i key` 한 번 더).

## 순서 제안
① 자산 원본을 볼트로 옮기고 배포.sh 가 거기서 복사하게(코드만 바꿈 · 안전) → ② 사장님 승인 → ③ 미러 백업 → ④ filter-repo → ⑤ force-push·재클론 → ⑥ 비밀 검사 → ⑦ 공개 전환.
