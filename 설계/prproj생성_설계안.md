# prproj 생성 — 이행 계획 (설계안, 보고용 · 구현 전)

작성 2026-08-17. 결정 근거: 사용자 최종 결정 "산출물은 **프리미어 파일(.prproj)을 열면 모든 소스가 제자리에 올라와 있는** 형태" (볼케이노와 같은 방식). FCP XML 수출(v0.6-import 까지 검증)은 **폴백·검증 발판으로 유지**한다. 관련 사실·근거: `참고_export.md` 9절(가족 prproj 해부)·10절(갈림길 결정), `가족인터뷰.md` Q1.

**매핑 표 골격** (채울 것):

| :---- | :---- | :---- |
| pics[k] (src_in/out, t0/t1, role) | `VideoClipTrackItem`(Start/End 틱) → `SubClip` → `VideoClip`(InPoint/OutPoint) → `VideoMediaSource` → `Media`(mp4) ; `ComponentChain`(Motion/Opacity 기본) ; `Link`(V1↔A1) | 틱 = 초 × 254016000000, 프레임 틱 10594584000(23.976) — 프레임 스냅 여부 결정 |
