# prproj 생성 — 이행 계획 (설계안, 보고용 · 구현 전)

작성 2026-08-17. 결정 근거: 사용자 최종 결정 "산출물은 **프리미어 파일(.prproj)을 열면 모든 소스가 제자리에 올라와 있는** 형태" (볼케이노와 같은 방식). FCP XML 수출(v0.6-import 까지 검증)은 **폴백·검증 발판으로 유지**한다. 관련 사실·근거: `참고_export.md` 9절(가족 prproj 해부)·10절(갈림길 결정), `가족인터뷰.md` Q1.

**원칙**: 계단식. 계단마다 끝에 **사람이 프리미어에서 열어 확인**한다. 어느 계단이 막히면 그 계단의 「되돌아갈 지점」으로 돌아가고, 최악에는 FCP XML 폴백으로 산출한다(파이프라인은 멈추지 않는다). 참고 폴더(`볼케이노 MCP/…/longformmovie_이관/pipeline`)는 **읽기만** — 코드를 복사하지 않고 구조 지식만 가져온다(우리 도너·우리 timeline.json 에 맞춰 새로 쓴다).

## 계단 0 — 학습 (읽기 전용)

**할 일**: 참고 폴더 `pipeline/stages/assemble.py`(7.9k줄, `ProjectDoc`·`HookProjectBuilder.build()` 순서·`_emit_*`·`_set_track_items`·`link_av_pairs`·`sanitize`)·`assemble_full.py`·`builders/timeline_builder.py`·`specs/textblob.py`(미니 FlatBuffers 리더/빌더, GT 블롭)·`specs/premiere_*.json`·`tools/normalize_prproj.py`·`verify()` 를 정독하고, **우리 timeline.json → prproj 요소 매핑 표**를 `설계/참고_prproj구조.md` 로 쓴다.

**매핑 표 골격** (채울 것):
| 우리 재료 (timeline.json / voice.json / 규격) | prproj 요소 (오브젝트 사슬) | 값·단위 |
| :---- | :---- | :---- |
| pics[k] (src_in/out, t0/t1, role) | `VideoClipTrackItem`(Start/End 틱) → `SubClip` → `VideoClip`(InPoint/OutPoint) → `VideoMediaSource` → `Media`(mp4) ; `ComponentChain`(Motion/Opacity 기본) ; `Link`(V1↔A1) | 틱 = 초 × 254016000000, 프레임 틱 10594584000(23.976) — 프레임 스냅 여부 결정 |
| pics[k].audio (keep/duck) | `AudioClipTrackItem` → `AudioClip` → `AudioMediaSource`(mp4 스트림) ; `AudioComponentChain` 의 볼륨 `Level` 파라미터(0.1778 = −15 dB, 0.0317 = −30 dB) ; 채널 레이아웃(SecondaryContents) | 레벨 = 10^(dB/20) 문자열 |
| nars[n] (wav, t0/t1) | 나레 wav 마다 `Media` + `AudioMediaSource`/`AudioStream` + `MasterClip` + `ClipProjectItem`(빈 등록) + 트랙 아이템 | 24000Hz mono 선언(ffprobe 실측으로 재작성) |
| 큐 cues[c] (lane, text, t0/t1) | 도너 텍스트 클립 서브트리 복제: `VideoClipTrackItem` → `SubClip`(이름=텍스트) → `VideoClip`(Graphic 소스, In=3600s) ; `VideoFilterComponent`(AE.ADBE Text) 파라미터 22개 중 **Source Text 블롭**(텍스트·폰트 PS 명·크기·색 런) · **Position**(정규화, 예: 0.5:0.9556) | 위치는 도너 견본에서 잡은 값을 **그대로 복제** — 계산하지 않음 |
| 트랙 목록 | `VideoTrackGroup`/`AudioTrackGroup` 의 `Track ObjectURef` ; 각 `VideoClipTrack`/`AudioClipTrack` 의 `ClipItems > TrackItems` | 도너 트랙 UID 고정, 아이템 목록만 교체 |
| 페이드 | `AudioTransitionTrackItem`(Constant Power, 4프레임) — 선택 사항 | 1차엔 생략 가능 |
| ObjectID | 도너 최대 ObjectID+1 부터 순차 할당(`alloc`) · `ObjectUID` 는 새 UUID · `Media` 의 `FileKey` 새 UUID · 블롭 `BinaryHash` = uuid28+hex8(len+12) 규칙 | 참고 폴더 `sanitize`/`verify` 지식 |
| gzip | `gzip.compress(xml.encode('utf-8'), 9, mtime=0)` ; XML 헤더·탭 들여쓰기·개행 원본 그대로 | 계단 2 에서 확정 |

**위험**: 참고 코드는 25fps 도너·세로 숏폼·훅 v17 특수 로직이 섞여 있어 그대로 옮기면 안 된다. 우리 필요 = V1/A1/A2/A3/V2/V3 + 텍스트 블롭 6가지 뿐 → 표에 **없는 것은 안 만든다**.
**검증**: 표의 각 줄이 가족 전달본(`벤치마크` 해부 결과)에서 실제로 관측된 오브젝트인지 대조.

## 계단 1 — 우리 도너 준비 (사람이 프리미어에서)

가족 도너(`real-edited-2026-v45-25fps.prproj`)는 **25fps** 라 우리 소재(23.976)와 다르고 Mac·영어 UI 출신이다. **사용자 본인 프리미어(26.3.2, 한국어 UI)로 우리 도너를 만든다** — 그래야 파라미터 이름·버전·폰트 환경이 산출물과 같다.

**절차서 초안** (`서버/README.md` 로 옮길 것):
1. 새 프로젝트 → 이름 `영화롱폼_donor_v1`, 저장 위치 `youstudio-mcp/도너/`(git 에 넣는다 — 규격의 일부).
2. 새 시퀀스: **1920×1080, 23.976fps(24 ntsc), 정사각 픽셀, 오디오 48kHz 스테레오** — 시퀀스 이름 `영화롱폼`.
3. 트랙: 비디오 **V1 원본컷 · V2 대사자막 · V3 나레자막**, 오디오 **A1 원본소리 · A2 나레 · A3 덕킹소리**(트랙 이름을 이렇게 붙인다 — 프로그램이 이름으로 찾는다). 여분 트랙은 지운다.
4. 원본 견본: Full Time mp4 를 프로젝트에 넣고 V1/A1 에 **컷 1개**(아무 2초) 올린다(미디어 사슬·V/A 링크 견본).
5. 나레 견본: `voice/b01.wav` 를 A2 에 1개, 같은 mp4 소리 컷 1개를 A3 에 올리고 **A3 클립 볼륨을 −12 dB**(규격 덕킹 레벨)로 — 오디오 레벨 파라미터 견본.
6. **자막 견본 2개** — 이것이 이 계단의 핵심(자막 위치 정밀 문제의 근본 해결):
   - V3 에 텍스트 클립 1개: 글자 "나레 견본", 폰트 **본명조 Bold(SourceHanSerifK-Bold)**, 크기 96, 흰색, 가운데 정렬, **위치를 눈으로 완벽히** 잡는다(1080 기준 y≈840, 지무비 자리). 정렬·행간·외곽선/그림자도 여기서 원하는 대로.
   - V2 에 텍스트 클립 1개: "대사 견본", **광화문(SDGwanghwamun)**, 크기 52, y≈980.
   - 견본을 편집한 뒤 **Essential Graphics 에서 위치 값을 읽어 적어 둔다**(참고용 — 프로그램은 값이 아니라 서브트리를 복제한다).
7. 저장 → 닫기 → 다시 열어 견본이 그대로인지 확인 → 그 파일이 도너.
8. 규격 「조립.도너」에 파일명·시퀀스명·트랙 이름·견본 클립 이름을 적는다.

**위험**: (a) 사용자가 산돌구름을 끈 채 만들면 폰트가 대체 폰트로 박힌다 → 절차 1번에 "산돌구름 켜기". (b) 프리미어 업데이트로 Version 이 바뀌면 도너 재제작 — 도너 파일명에 프리미어 버전을 넣는다(`…_ppro26.3.prproj`). (c) 도너에 잔재(빈 트랙·시험 클립)가 남으면 산출물에 딸려간다 → 3~6번 외 아무것도 넣지 않는다.
**검증**: 도너를 풀어 `참고_prproj구조.md` 표대로 오브젝트가 있는지(트랙 6, 텍스트 클립 2, Media 3) 스크립트로 센다 → 숫자가 맞아야 계단 2.
**되돌아갈 지점**: 절차서를 고쳐 다시 만든다(비용: 사람 15분).

## 계단 2 — 왕복 실험

**할 일**: 도너를 복제 → gzip 풀기 → **아무것도 안 바꾸고** 다시 gzip(mtime 0, 레벨 9) → 다른 이름으로 저장 → 프리미어에서 열기. 이어서 "한 글자만 바꾸기"(시퀀스 이름 끝에 `_2`) 판도 연다.
**검증**: 열림·경고창 0·트랙/클립 그대로. 풀었다 싼 XML 이 바이트 단위로 원본과 같은지(`diff`)도 본다 — 다르면 인코딩/개행/BOM 규칙을 계단 0 표에 적는다.
**위험**: 프리미어가 프로젝트를 여는 순간 다시 저장하려 하면(변환) 원본을 건드릴 수 있다 → 항상 복제본으로 연다.
**되돌아갈 지점**: 계단 0 의 gzip/인코딩 규칙.

## 계단 3 — 치환 사다리 (한 계단씩, 계단마다 사람이 연다)

**3-a 컷 1개**: 도너 V1/A1 견본 컷의 In/Out/Start/End 만 timeline.json 의 첫 컷으로 바꾼다(오브젝트 추가 없음). → 열어서 그 컷이 맞는 장면·소리인지.
  위험: 틱 계산(프레임 스냅 vs ms). 검증: 프리미어 타임코드가 timeline.json 초와 ±1프레임. 되돌아갈 지점: 2.
**3-b 컷 전체**: 견본 컷 서브트리를 46번 복제(ObjectID 재할당, SubClip 이름 = 컷 이름), V1/A1 트랙 아이템 목록 교체, V/A `Link` 46쌍. → 총 길이 553.4s, 컷 46, A1 36(살릴 컷)… 이 계단에서 A1 은 전 컷을 두고 레벨은 아직 손대지 않는다.
  위험: 트랙 아이템 순서·겹침·ObjectID 충돌 → 검증 스크립트(파싱해서 겹침 0·개수 일치) + 프리미어 열기. 되돌아갈 지점: 3-a.
**3-c 오디오 배치**: A2 나레 27개(wav 마다 Media 사슬 신규) + A3 덕킹 컷 10개(볼륨 −12 dB 견본 복제, A1 에서는 뺀다) + (선택) 4프레임 페이드. → 나레가 제자리에서 들리고 덕킹 컷이 작게 들리는지.
  위험: wav 스트림 선언(24000Hz mono)·미디어 오프라인(절대경로 규칙). 검증: 프로젝트 패널에 오프라인 0, A2 27/A3 10. 되돌아갈 지점: 3-b (오디오는 FCP XML 로 검증된 재료라 실패 원인은 prproj 표현뿐).
**3-d 자막(블롭 치환)**: 도너 텍스트 클립 2개(나레·대사 견본)를 큐 수만큼 복제하고 **Source Text 블롭의 텍스트만 치환**(폰트·크기·색·위치는 견본 그대로 → 정밀 위치 자동 해결). 블롭은 FlatBuffers — 텍스트 길이가 바뀌면 오프셋 재계산(참고 폴더 textblob 지식: tail relocation·BinaryHash 갱신·InstanceName 동기화). 1차는 **한 큐 = 한 폰트·한 크기**만(런 분할 없음).
  위험(가장 큼): 블롭 구조 오독 → 프리미어가 클립을 버리거나 크래시. 검증: 사다리 안의 사다리 — ① 견본 텍스트를 같은 길이 다른 글자로 → ② 더 짧게 → ③ 더 길게·2줄 → ④ 194큐 전부. 되돌아갈 지점: 3-c, 그리고 **자막만 폴백** — SRT 임포트 또는 FCP XML(origin) 로 자막을 넣고 나머지는 prproj.

## 계단 4 — export 통합

**할 일**: export ② 가 `.prproj` 를 본선 산출물로 쓰고(`render/<영화>.prproj` + `media/` 배치 규칙 — 가족처럼 산출 폴더 기준 절대경로), FCP XML·SRT·믹스·manifest 는 그대로 부산물로 낸다. 게이트: 기존 10개 + **prproj 자기검증**(파싱해서 트랙별 개수 = timeline 실측, 겹침 0, ObjectID 중복 0, 오프라인 후보 0, gzip 왕복 동일) 을 hard 로. 규격 「조립.내보내기」에 `형식: prproj(본선) / fcpxml(폴백)` 스위치.
**사람 확인**: 본편 prproj 를 새 폴더에서 열기 → 자막 위치·폰트·오디오·컷 → 이정표 `v0.7-prproj`.
**위험**: 산출 폴더 이동 시 미디어 오프라인 → 가족처럼 `읽어주세요` 성격의 안내(Link Media 한 번)를 manifest 에.
**되돌아갈 지점**: 3-d / 최악엔 규격 스위치로 FCP XML 폴백.
