## 1. 얽힌 항목 — 따로 고치면 깨진다

```
  나레 글자 크기 ↓  ──→  한 줄 자수 상한 ↑  ──→  줄바꿈 규칙(집필 lines[])
        │                      │                        │
        └──────→ 자막 레인 하나로 합치기 ←───────────────┘
                        │
                  교차겹침·커버율 게이트 재측정
```

- **크기 ↔ 자수 ↔ 줄바꿈은 한 세트다.** 글자를 줄이면 한 줄에 더 들어가므로 `자막.나레_한줄_최대자수`(지금 18)를 다시 정해야 하고, 그러면 집필자가 나눈 `lines[]`가 전부 다시 나뉘어야 한다(대본 재집필은 아니고 줄 나눔만 — 음성 재합성 없음).
- **레인 합치기**는 크기 결정 뒤에 한다. 같은 자리에 두 종류가 오가므로 크기·색이 구분의 유일한 수단이 된다.
- **밀도 3종**은 select·script 단계라 자막과 독립이다 — 병행 가능.

## 2. 반영 순서 (각 단계마다 재생성·검증)

| 순 | 무엇 | 건드리는 곳 | 검증 |
| :-- | :-- | :-- | :-- |
| 1 | **나레 글자 크기 축소** | 규격 `자막.크기_px`(96 → 실측 대역), 도너 견본 서식 | prproj 열어 눈으로 — 화면 대비 4~6%인가 |
| 2 | **한 줄 자수 상한 재산정** | 정답지 `G-자막_한줄_최대자수.나레`(18 → ?) | 실제 렌더에서 한 줄이 화면 폭을 넘지 않는가 |
| 3 | **줄 나눔 다시** | script `lines[]` 27블록 소급(음성 재합성 없음) | `G-줄바꿈` 확정 위반 0 |
| 4 | **레인 하나로** | 규격 `자막.위치`(나레·대사 같은 y), export·조립기 | `G-교차겹침` 0 유지 · prproj 눈 확인 |
| 5 | **강조 도입** | 규격 `자막.강조`(색·배수·큐당 상한), `강조.md` 신설, script 가 강조 후보 표시, 조립기가 런 서식 분리 | 강조 비율이 정답지 대역 안인가 · prproj 에서 색·크기가 실제로 다른가 |
| 6 | **효과음 도입** | 음원 확보 → 규격 `조립.효과음` → export 가 A4 트랙 배치 | 붙는 자리 구성비가 대역 안인가 · 소리가 나레를 가리지 않는가 |
| 7 | **밀도 3종** | select 곡선(컷), script 지침(나레 분당 단어 56~60), 죽은시간 대역 | Full Time 재생성 후 세 지표 |

**1~4는 한 묶음**(자막 모양), **5~6은 새 기능**, **7은 독립**. 묶음 안에서는 순서를 지킨다.

## 3. 검증 방법 — Full Time 재생성 후 무엇을 보나

| 지표 | 지금 | 2판 목표 | 어디서 |
| :-- | :-- | :-- | :-- |
| 나레 글자 높이 | 8.9% | **4~6%** | 규격 값 + prproj 눈 확인 |
| 한 줄 자수(나레) | 18 | 재산정값 | `G-자막(한 줄 자수)` |
| 줄바꿈 확정 위반 | 0 | **0 유지** | `G-줄바꿈` |
| 교차 겹침 | 0 | **0 유지**(레인 합친 뒤에도) | `G-교차겹침` |
| 나레 커버율 | 1.000 | **≥0.98 유지** | `G-나레커버율` |
| 나레 단어일치 | 0.985 | **≥0.7 유지** | `G-나레단어일치` |
| 분당 나레 단어 | 26.1 | **56~60 쪽으로** | 새 지표(script) |
| 컷 길이 중앙 | 4.49s | 축을 맞춘 뒤 판단 | select |
| 죽은 시간 | 0.091 | 대역 재검토 | `G-죽은시간` |

**사람 확인**: 각 묶음이 끝날 때마다 `render/<영화>.prproj` 를 열어 ① 자막이 읽히는 크기인가 ② 한 레인에서 나레·대사가 구분되는가 ③ 강조가 의미 있는 단어에 붙었는가 ④ 효과음이 거슬리지 않는가.

## 4. 하지 않을 것

- **결말 비공개로 바꾸기** — 강제 규칙(HARNESS). 지무비가 0/10이어도 되돌리지 않는다.
- **지무비 마무리 문구 베끼기** — 「감사합니다 지무비였습니다」 같은 채널 정체성은 가져오지 않는다. 우리 CTA·마무리는 결말을 공개하는 구조에 맞게 따로 설계한다.
- **무자막 최장·문장 자수 대역 반영** — 우리 검출 한계로 보류(정답지에 사유 기록).
- **계측 항목 추가** — 현재 항목(컷·발화·레인·글자 크기·큐)으로 동결(사용자 2026-08-18).

## 5. 열어 둔 것

- **강조 표본이 앞부분에 치우쳐 있다**(영상 앞 2~22%). 5번(강조 도입) 전에 중간·끝 구간을 클립으로 다시 판독하면 표본이 고르게 된다 — 편당 약 9K 토큰, 결말 재판독과 같은 방식.
