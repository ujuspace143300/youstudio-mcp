# 지인이 자기 MCP 를 처음부터 세우게 하기 — 계획 (예: 김스튜디오 MCP)

> 2026-09-18 사장님: «지인이 김스튜디오 MCP 를 만들고 싶어 한다. 우리가 구축한 노하우와 정보를 그대로 이식해 주고 싶다.»
> 같은 날 못 박은 것 세 가지 — ① **옵시디언 없이**(볼케이노처럼 한 줄 설치) ② **깃허브 저장소·서버는 그 사람이 새로 만든다 — 아예 처음부터 구축하는 그림** ③ **프리셋은 전달하지 않는다. MCP 의 구조가 제일 중요하다.**
> 그래서 이 계획은 «포크»도 «임차»도 아니다. 우리가 넘기는 것은 **구조와 구축 노하우**이고, 코드·계정·프리셋은 전부 그 사람 것이다.
> **2026-09-18 실행 결과**: 꾸러미를 만들었다 — `~/Desktop/김스튜디오-MCP-꾸러미/` + 같은 이름 `.zip`(바탕화면). 뼈대(코드 ≈2,100줄 + 예시 프리셋) 는 typecheck · 스모크 41항목 · 인증 27항목 · KV 대장 17항목 전부 통과, 실행기로 실물 mp4 한 바퀴 완주, 이름바꾸기 사본 시험 통과. 설명서 3종(구조·구축순서·함정 27개) + 처음읽기 동봉. 우리 저장소는 한 줄도 안 바꿨다(이 문서만 추가).
> 이 문서는 계획이었고 위 결과로 실행됐다. 관련: `HARNESS.md` · `서버/README.md` · `인증_이메일허가제.md` · `이식원칙_볼케이노에서_유스튜디오로.md`.

## 한 줄 결론

유스튜디오에서 **프리셋과 자산을 빼면 약 2,100줄의 뼈대**가 남는다(도구 1개짜리 MCP 서버 · 응답 봉투 · 상태 머신 · 프리셋 등록표 · 게이트 규약 · 이메일 허가제 대장 · 관리 페이지 · 토큰 인증 자산 · 러너 · 한 줄 설치 · 시험 · 배포). 이 뼈대가 곧 «MCP 의 구조»다. 지인에게는 **① 구조 설명서 ② 구축 순서서 ③ 함정 목록 ④ 돌아가는 뼈대 코드(예시 프리셋 1개)** 네 가지를 꾸러미로 주고, 지인은 자기 GitHub·자기 Cloudflare 에서 그 순서대로 세운다. 프리셋(어떤 영상을 어떻게 만들지)은 지인이 자기 채널에 맞게 처음부터 짓고, 우리는 «프리셋 짓는 법»만 준다.

## 지인에게 가는 꾸러미 4가지

### ① 구조 설명서 (`김스튜디오_구조.md` · 목표 300줄 안)
그 사람의 클로드코드가 읽고 그대로 지을 수 있게. 장 구성:
1. 큰 그림 — 서버는 판단·규격·순서, 러너는 손. 서버에 상태 없음(요청마다 새 McpServer), 상태는 클라이언트 작업 폴더.
2. MCP 표면 — 도구 1개 `<이름>_video`, 입력 스키마(`step` enum 은 프리셋 steps 의 합집합에서 파생 · `preset` · `source` 판별유니언 · `payload` 자유 사전), SDK `createMcpHandler(stateless)`, HTTP 경로 4개(`/health` `/admin` `/asset/…` `/`).
3. 응답 봉투 — 칸마다 뜻·필수 여부, `jobs_kind` 6종, `auth:{env}` 로 키 이름만, `reject(why, fix)` 는 fix 강제.
4. 러너 — 고정 순서, carry 규칙(응답값→옛 payload→기본 칸→실측), 종료코드(1 반려·2 입력 필요·3 유료 승인·0 완료), `--state`·`--until`·`--from`, argv 는 `python` 첫 토막만 venv 로 바꾸고 나머지는 안 건드림, «같은 단계 여러 번 부르기» 관용구.
5. 프리셋 등록 — `Style` 인터페이스, 정적 import(Workers 에 파일시스템 없음), `.md` 텍스트 import 규칙, 등록표, `setup` 은 공유·`start` 는 프리셋마다, `lib.ts` 에 carry 계약.
6. 게이트 — `gates[]`(pass true/false/null · hard/soft · detail 에 «잰 값·대역·출처» · fix) 와 검사표+반려 두 꼴, 사람 확인 항목은 `human_ok` 없이는 다음 단계 반려.
7. 스타일 숫자 3파일 — 정답지/규격/우리실측, `_안내`·`_스키마` 첫 키, 폐기값은 지우지 말고 `_주의` 로 병기.
8. 인증 — 6검사 순서(프리셋 검사가 기기 등록보다 먼저인 이유), 대장 한 줄, 토큰=KV 키, id=sha256 앞 16자, 3단 폴백(KV→단일 토큰→없음), 관리 API 10개, CLI 명령.
9. 자산 — `_index.json` 이 사람 경로↔ASCII 키를 잇는다, `run_worker_first`, `no-store`, NFC, sha256.
10. 설치·시험·배포 — 8단계 요지, dev-smoke(KV 줄만 뺀 임시 설정)·kv-smoke·auth 단위시험, `배포.sh` 6순서.
11. 새 프리셋 추가 절차 (파일 4개·10줄) 와 새 단계 추가 절차(3곳).

### ② 구축 순서서 (`김스튜디오_구축순서.md`)
지인이 자기 클로드코드에게 **한 단계씩** 시키는 대본. 단계마다 «끝났다는 증거»가 있다.

### ③ 함정 목록 (`김스튜디오_함정.md`)
코드 주석·README 에 박힌 구조 함정 16개를 «증상 → 원인 → 구조로 막은 법» 꼴로. 예: 배포본 한글 경로 404(→ASCII 키+인덱스) · 맥 NFD(→NFC 양쪽) · raw URL 한글(→설치 파일명 ASCII) · 윈도우 spawnSync 헤더 쪼개짐(→cmd /d /s /c verbatim) · KV id 비면 dev 안 뜸(→임시 설정) · KV 없는 스모크는 인증을 못 잡음(→시험 둘로) · 토큰 평문 금지 · body 두 번 읽기(→clone) · 프리셋 권한 기본 거부라 initialize 는 건너뜀 · SSE 응답 · structuredContent 없을 때 · carry 빈 응답 뒤 기본 칸 유실 · 규격 고치고 배포 안 하면 컴퓨터마다 다른 서버 · 러너가 임시 폴더에만 있으면 없는 것 · «명령 있나» 말고 «진짜 버전 뱉나» · 볼케이노 서버를 런타임에 부르지 않는다(남의 서버 의존).
운영 노하우도 여기에: 완성 보고 전 검사 전부 통과 · 땜질 금지(실측→클래스→구조→게이트→재실측) · 확인한 것과 짐작 구분 · 유료 단계 전 비용 승인 · 한글 이스케이프·heredoc 금지 · 값을 지어내지 않는다.

★뼈대는 «출발점»이지 «정답»이 아니다. 지인의 클로드가 설명서만 보고 처음부터 짓는 것도 가능하고, 그게 이해에는 더 좋다. 뼈대는 그 옆에 두고 «막히면 여기서 베낀다» 용도다. 어느 쪽이든 §0 에서 사장님이 정한다.

## §0. 사장님이 먼저 정할 것

1. **꾸러미 형태** — (a) 설명서 3종만 (b) 설명서 3종 + 뼈대 코드. 추천 (b): 인증·자산·설치 세 뭉치는 우리가 함정 16개를 밟고 얻은 것이라 설명서만으로는 다시 밟는다.
2. **뼈대 이름** — 예시 상수 값(김스튜디오 / `kimstudio-mcp` / `kimstudio_video` / `~/.kimstudio`). ASCII 만.
3. **한국어 공통 라이브러리 2개**(`lib/줄바꿈.ts` 185줄 · `lib/단어정렬.ts` 106줄)는 프리셋 무관이지만 «한국어 영상 자막» 도메인 코드다. 줄지 말지.
4. **전달 방식** — 압축 파일 + 반나절 자리(같이 앉아 §4 단 7~8 까지) 를 추천. 문서만 던지면 «어디까지 왔나»를 우리가 모른다.
5. **그 뒤 관계** — 지인이 막힐 때 묻는 창구(사장님 → 클로드), 우리 개선을 나중에 알려 줄지(구조가 바뀌면 설명서 판을 올려 준다 · 코드 pull 관계는 없음).

## §1. 우리 쪽에서 할 일 (사장님 컴퓨터 · 클로드가 한다)

1. **뼈대 추출** — 저장소에서 프리셋 무관 파일 목록(위 표)을 새 폴더로 복사. 프리셋 상수 참조(`styles.ts` import 3줄 · `steps/index.ts` 지도 · `smoke.mjs` 단계 부분 · `실행기.py` 의 `PAID_MARK`·기본 프리셋) 를 예시 프리셋으로 바꾼다. 브랜드 상수 `STUDIO` 한 파일로 모은다(우리 저장소는 안 건드린다 — 뼈대는 별개 산출물).
2. **예시 프리셋** — `스타일/예시/` 3파일 + `steps/예시/start.ts`·`hello.ts`(ffprobe 로 길이 재서 `metrics` 에 넣고, 정답지 대역과 비교해 `gates[]` 하나) · 러너로 로컬 한 바퀴.
3. **비밀·개인 흔적 제거** — 절대경로(`/Users/yustudio1`·`C:/Users/user`) · 이메일 · `groove1027` · `규격서` · `volcano` 문자열 · KV id · 배포 URL. grep 0건이 관문.
4. **스모크 통과** — `dev-smoke` · `kv-smoke` · `auth` 셋 다 초록. 깨끗한 폴더에서 `npm i` 부터 다시 한 번.

## §2. 지인 쪽에서 일어나는 일

- 지인은 자기 클로드코드에 ①②③ 을 읽히고 «구축 순서서 단 1부터» 시킨다. 뼈대(④)는 옆 폴더에 두고 참고.
- GitHub 새 저장소(비공개로 시작), Cloudflare 계정, `wrangler login`, KV·ADMIN_TOKEN 전부 지인 명의. 우리 값은 하나도 안 들어간다.
- 단 8 까지가 «MCP 구조 완성». 여기까지는 유료 API 도 프리미어도 필요 없다(예시 프리셋은 ffmpeg 만).
- 단 9 «자기 프리셋»부터가 지인의 본업이다. 어떤 영상인지·어떤 게이트인지·어떤 API 를 쓸지는 지인이 정한다. 우리는 «스타일 3파일부터 시작하라, 정답지를 먼저 재라, 단계마다 두 국면으로 나눠라» 만 준다.
